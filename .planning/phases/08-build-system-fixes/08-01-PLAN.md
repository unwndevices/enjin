<task type="auto">
  <name>Make Lua dependency optional in CMake</name>
  <files>CMakeLists.txt</files>
  <action>
    Modify CMakeLists.txt to make Lua truly optional:

    1. Keep the existing `option(ENJIN2_BUILD_LUA "Build Lua bindings" ON)` at line 34 - this is the correct option name.

    2. In the Lua handling block (lines 86-149), change the desktop platform section:
    
    Find this code at line 124:
    ```cmake
    else()
        # Desktop platforms - use system Lua
        find_package(Lua REQUIRED)
    endif()
    ```

    Replace with:
    ```cmake
    else()
        # Desktop platforms - use system Lua
        find_package(Lua QUIET)
        
        # Provide clear error if Lua was requested but not found
        if(NOT Lua_FOUND AND ENJIN2_BUILD_LUA)
            message(FATAL_ERROR
                "Lua was requested (ENJIN2_BUILD_LUA=ON) but could not be found.\n"
                "Install Lua from https://lua.org/ or set ENJIN2_BUILD_LUA=OFF to build without Lua support.\n"
                "Package managers:\n"
                "  Debian/Ubuntu: apt-get install liblua5.1-dev\n"
                "  macOS: brew install lua\n"
            )
        endif()
    endif()
    ```

    Why: The current `find_package(Lua REQUIRED)` makes Lua mandatory when ENJIN2_BUILD_LUA is ON, which fails docs deployment. Making it optional (QUIET) allows the build to proceed when ENJIN2_BUILD_LUA is OFF, while providing a clear error message when Lua is requested but unavailable.
  </action>
  <verify>
    Run CMake configuration with both ON and OFF states:
    
    ```bash
    mkdir -p build_lua_on && cd build_lua_on
    cmake -DENJIN2_BUILD_LUA=ON ..
    
    cd ..
    rm -rf build_lua_on
    mkdir -p build_lua_off && cd build_lua_off
    cmake -DENJIN2_BUILD_LUA=OFF ..
    ```
    
    Expected result:
    - ENJIN2_BUILD_LUA=ON: Should configure successfully if Lua is installed, or show clear error if Lua is missing
    - ENJIN2_BUILD_LUA=OFF: Should configure successfully without Lua
  </verify>
  <done>
    CMakeLists.txt successfully configures in both states (ON and OFF). When ON and Lua is missing, error message is displayed with installation instructions.
  </done>
