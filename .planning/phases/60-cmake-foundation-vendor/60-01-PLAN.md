<task type="auto">
  <name>Task 2: Patch root CMakeLists.txt with ENJIN2_BUILD_BENCHMARKS option and verify builds</name>
  <files>CMakeLists.txt</files>
  <action>
1. Edit root `CMakeLists.txt` to add the benchmark option and guard. Insert AFTER the `ENJIN2_BUILD_TESTS` / `add_subdirectory(tests)` block (lines 254-257) and BEFORE the WASM section (line 260). Add:
   ```cmake
   # Benchmarks (desktop only — nanobench requires POSIX/Linux perf headers)
   option(ENJIN2_BUILD_BENCHMARKS "Build nanobench benchmark suite (desktop only)" OFF)

   if(ENJIN2_BUILD_BENCHMARKS)
       if(EMSCRIPTEN OR ESP32)
           message(FATAL_ERROR "ENJIN2_BUILD_BENCHMARKS is not supported on WASM or ESP32 targets")
       endif()
       add_subdirectory(benchmarks)
   endif()
   ```
   This mirrors the existing `ENJIN2_BUILD_TESTS` pattern exactly.

2. Verify the ON build:
   ```bash

   cmake --build /tmp/enjin_bench_on --target bench_smoke
   /tmp/enjin_bench_on/benchmarks/bench_smoke
   ```

   The smoke benchmark must run and print timing output to stdout.
