<objective>
Migrate all update/lateUpdate signatures from `uint16_t deltaTime` (milliseconds) to `float dt` (seconds) throughout the entire C++ update chain — base classes, concrete components, scene state machine, animation system, effects, and Lua bridge.

Purpose: DT-01 and DT-02 require float dt in seconds everywhere. This is the foundational change that all subsequent v1.5 phases build on. The SDL platform layer already computes `float dt` — this plan propagates that type through the entire call chain.

Output: All engine update signatures accept `float dt`, all accumulators store float seconds, all `/1000` divisions removed, PostFx periodic trigger uses sub-accumulator.
</objective>
