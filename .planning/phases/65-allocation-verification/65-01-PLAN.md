**1. Create `include/enjin2/instrumentation/alloc_guard.hpp`:**

Header-only RAII class following the frame_timing.hpp pattern. Two compilation paths:

- `ENJIN2_ALLOC_VERIFICATION` defined: Full AllocGuard with extern thread_local declarations for `g_alloc_guard_depth` (int) and `g_alloc_count` (long). Constructor increments depth and records count baseline. Destructor decrements depth and checks delta — if > 0, prints `[ALLOC-FAIL] {label}: {N} allocation(s) detected in hot path` via fprintf(stderr) and calls exit(1). Non-copyable, non-movable (delete copy/move ctors/operators).

- `ENJIN2_ALLOC_VERIFICATION` not defined: No-op stub — constructor takes `const char*` and does nothing. Destructor does nothing. Same delete pattern for copy/move.

Include `#pragma once`, `<cstdio>`, `<cstdlib>`. Place in `namespace enjin2`.

**2. Create `benchmarks/bench_alloc.cpp`:**

Structure (order matters — operator new override MUST come before allocating includes):

a) `#define ENJIN2_ALLOC_VERIFICATION 1` at the very top.

b) Define `thread_local int g_alloc_guard_depth = 0;` and `thread_local long g_alloc_count = 0;` as file-scope variables (NOT static — the header declares them extern).

c) Override all six operator new/delete forms (per C++14 sized deallocation):
   - `void* operator new(std::size_t size)` — if `g_alloc_guard_depth > 0`, increment `g_alloc_count`; call `std::malloc(size)`; if nullptr throw `std::bad_alloc()`
   - `void* operator new[](std::size_t size)` — delegate to `::operator new(size)`
   - `void operator delete(void* ptr) noexcept` — `std::free(ptr)`
   - `void operator delete[](void* ptr) noexcept` — `std::free(ptr)`
   - `void operator delete(void* ptr, std::size_t) noexcept` — `std::free(ptr)`
   - `void operator delete[](void* ptr, std::size_t) noexcept` — `std::free(ptr)`

d) `#include <enjin2/instrumentation/alloc_guard.hpp>` (now sees the extern declarations)

e) Include engine headers: `<nanobench.h>` (NOT with IMPLEMENT define — bench_alloc doesn't need nanobench benchmarks, only `doNotOptimizeAway`), `<enjin2/graphics/canvas.hpp>`, `<enjin2/graphics/primitives.hpp>`, `<enjin2/core/scene.hpp>`, `<enjin2/scripting/lua_engine.hpp>`, `<enjin2/scripting/bindings.hpp>`, `<cstdio>`.

IMPORTANT: Do NOT `#define ANKERL_NANOBENCH_IMPLEMENT` — bench_alloc uses only `doNotOptimizeAway` which is header-only. Including the implementation definition would cause linker errors if bench_alloc is built alongside other bench targets that also define it (each is a separate binary so this is actually fine, but it's unnecessary bloat). Actually, since each benchmark is a separate binary, defining IMPLEMENT is safe. Use `#define ANKERL_NANOBENCH_IMPLEMENT` before `#include <nanobench.h>` to match the existing bench binary pattern.

f) Create BenchScene class (minimal concrete Scene, same pattern as bench_ecs.cpp):
```cpp
class BenchScene : public enjin2::Scene {
public:
    BenchScene() : enjin2::Scene(1) {}
};
```

g) `int main()` with two sections:

**SETUP SECTION** (allocations allowed):
- Create `Canvas4<128,128> canvas` and `Canvas4<128,128> sprite` on the stack
- `sprite.clear(Pixel4(5))`
- Create `BenchScene scene`, call `scene.activate()`, add 8 objects via `scene.addObject<enjin2::Object>()` loop
- Create `LuaEngine eng`, call `eng.initialize()`
- Create `LuaBindings bindings(&eng)`, call `bindings.registerAll()`
- Store a registry reference to `engine.time.delta` function for zero-alloc calling:
  ```cpp
  lua_State* L = eng.getState();
  lua_getglobal(L, "engine");
  lua_getfield(L, -1, "time");
  lua_getfield(L, -1, "delta");
  int deltaRef = luaL_ref(L, LUA_REGISTRYINDEX);
  lua_pop(L, 2);  // pop time, engine
  ```
- Reset counter: `g_alloc_count = 0;`

**HOT PATH SECTION** (AllocGuard wraps each operation):

Canvas ops (ALLOC-03 canvas requirement):
- `AllocGuard g("canvas4: setPixel")` + `canvas.setPixel(64, 64, Pixel4(7))` + `doNotOptimizeAway(canvas.getPixel(64, 64))`
- `AllocGuard g("canvas4: clear")` + `canvas.clear(Pixel4(0))` + `doNotOptimizeAway(canvas.getPixel(0, 0))`
- `AllocGuard g("canvas4: fillRect 32x32")` + `canvas.fillRect(0, 0, 32, 32, Pixel4(3))` + `doNotOptimizeAway(canvas.getPixel(16, 16))`
- `AllocGuard g("canvas4: blit 128x128 sprite")` + `canvas.blit(sprite, 0, 0, Pixel4(0))` + `doNotOptimizeAway(canvas.getPixel(64, 64))`

Component update dispatch (ALLOC-03 component update requirement):
- `AllocGuard g("scene::update x8 objects")` + `scene.update(0.016f)` + `doNotOptimizeAway(scene.getObjects().size())`

Lua binding call (ALLOC-03 Lua binding requirement):
- Use the pre-registered deltaRef to call without executeString:
  ```cpp
  {
      enjin2::AllocGuard g("lua binding: engine.time.delta call");
      lua_rawgeti(L, LUA_REGISTRYINDEX, deltaRef);
      lua_call(L, 0, 1);
      ankerl::nanobench::doNotOptimizeAway(lua_tonumber(L, -1));
      lua_pop(L, 1);
  }
  ```

CRITICAL: Do NOT use `eng.executeString()` inside any AllocGuard — `luaL_loadstring` allocates for chunk parsing. Call binding via `lua_rawgeti` + `lua_call` on the pre-registered reference.

Cleanup: `luaL_unref(L, LUA_REGISTRYINDEX, deltaRef)`, `eng.shutdown()`

Print success: `fprintf(stdout, "[ALLOC-PASS] All hot-path allocation checks passed\n");`
Return 0.
