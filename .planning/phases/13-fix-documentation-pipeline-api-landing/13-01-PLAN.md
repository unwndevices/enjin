Apply these changes to scripts/generate-api-docs.js:

**1. Add `classNameToXmlFilename` helper function** (before `processClass`):

```javascript
function classNameToXmlFilename(className, prefix) {
  const parts = className.split('::');
  const encodedParts = parts.map(part => part.replace(/_/g, '__'));
  return `${prefix}${encodedParts.join('_1_1')}.xml`;
}
```

This encodes underscores BEFORE joining with `_1_1`, matching Doxygen's encoding where `_` in identifiers becomes `__` in filenames.

**2. Update `processClass` XML lookup** (lines 209-212) to use the new helper and add struct prefixes:

Replace the `possibleNames` array with:
```javascript
const possibleNames = [
  classNameToXmlFilename(className, 'classenjin2_1_1'),
  classNameToXmlFilename(className, 'classenjin_1_1'),
  classNameToXmlFilename(className, 'structenjin2_1_1'),
  classNameToXmlFilename(className, 'structenjin_1_1'),
];
```

The struct prefixes are needed for the compat module's `enjin::Vector3` (which is a struct, not a class).

**3. Fix `sanitizeClassName`** (line 194): Remove the `/__/g, '_'` line that collapses double underscores. This line breaks C_ class names by turning `C_Animation` into `CAnimation`. The fixed function:

```javascript
function sanitizeClassName(name) {
  return name
    .replace(/::/g, '_')
    .replace(/<[^>]*>/g, '')
    .replace(/\s+/g, '');
}
```

**4. Update config entries** to use `::` notation:
- `core.classes`: Change `'ComponentQuery_Iterator'` to `'ComponentQuery::Iterator'` and `'ComponentStorage_Iterator'` to `'ComponentStorage::Iterator'`
- `utils.classes`: Change `'math_TrigLUT'` to `'math::TrigLUT'`

**5. Add compat module** to `config.modules`:

  classes: ['Vector3'],
  description: 'Compatibility layer for enjin1 integration',

Place it alphabetically after `animation` in the modules object.

**6. Fix Effects routing conflict** in `processClass`: When writing the output file, if the sanitized class name matches the module directory name (case-insensitive), append `Class` to the output filename. Change the output file writing section:

Also update the markdown frontmatter `id` to use `outputName` instead of `className` when there's a conflict, so `Effects` becomes `EffectsClass` in the id field. Remove the slug-based workaround (the `needsSlug`/`slugLine` code around lines 267-270) since the filename rename makes it unnecessary.
