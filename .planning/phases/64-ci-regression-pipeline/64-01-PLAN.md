Create `scripts/convert-bench.py` that:

1. Reads `bench-results/bench_canvas.json`, `bench-results/bench_ecs.json`, `bench-results/bench_lua.json`
2. For each entry in `results[]` array:
   - Extract `name` (use as-is -- names are already globally unique across files)
   - Extract `median(elapsed)` in seconds, multiply by 1e9 to get nanoseconds, round to 4 decimal places
   - Extract `medianAbsolutePercentError(elapsed)`, multiply by 100 to get percent, format as string with +/- prefix (e.g., `"± 4.55%"`)
   - Build object: `{"name": ..., "unit": "ns/op", "value": ..., "range": ...}`
3. Combine all entries into a single JSON array
4. Write to `bench-results/bench-combined.json` with indent=2

Use `os.path` relative to script location (`os.path.dirname(__file__)`) to find `bench-results/` directory (one level up from scripts/).

Use only stdlib (json, os, sys) -- no external dependencies.

Exit non-zero with a clear error message if any input file is missing or has zero results.

<task type="auto">
  <name>Task 2: Create GitHub Actions benchmarks workflow</name>
  <files>.github/workflows/benchmarks.yml</files>
  <action>
Create `.github/workflows/benchmarks.yml` with the following structure:

**Name:** `Benchmarks`

**Triggers:**
- `push` to `main` branch, paths: `src/**`, `include/**`
- `pull_request`, paths: `src/**`, `include/**`
- `workflow_dispatch` (manual trigger for initial seed run and debugging)

**Concurrency:**
- Group: `benchmarks-${{ github.ref }}`
- `cancel-in-progress: false` (do NOT cancel -- bench-data push must complete)

**Single job: `benchmark`**
- `runs-on: ubuntu-latest`
- `permissions: contents: write` (needed for auto-push to bench-data)

**Steps (in order):**

1. `actions/checkout@v4`

2. **Install dependencies:**
   ```
   sudo apt-get update -qq
   sudo apt-get install -y liblua5.4-dev
   ```

3. **Build and run benchmarks:** `bash scripts/build-bench.sh`

4. **Convert to customSmallerIsBetter format:** `python3 scripts/convert-bench.py`

5. **Store benchmark result (push to main or manual trigger):**
   - `if: github.event_name == 'push' || github.event_name == 'workflow_dispatch'`
   - `uses: benchmark-action/github-action-benchmark@v1`
   - `with:`
     - `name: enjin2 Benchmarks`
     - `tool: customSmallerIsBetter`
     - `output-file-path: bench-results/bench-combined.json`
     - `gh-pages-branch: bench-data`
     - `benchmark-data-dir-path: dev/bench`
     - `github-token: ${{ secrets.GITHUB_TOKEN }}`
     - `auto-push: true`
     - `comment-always: false`

6. **Check for regression (PR only):**
   - `if: github.event_name == 'pull_request'`
   - `uses: benchmark-action/github-action-benchmark@v1`
   - `with:`
     - `name: enjin2 Benchmarks`
     - `tool: customSmallerIsBetter`
     - `output-file-path: bench-results/bench-combined.json`
     - `gh-pages-branch: bench-data`
     - `benchmark-data-dir-path: dev/bench`
     - `github-token: ${{ secrets.GITHUB_TOKEN }}`
     - `auto-push: false`
     - `save-data-file: false`
     - `alert-threshold: '150%'` (per project decision -- shared runner variance is high)
     - `fail-on-alert: true`
     - `comment-on-alert: true`

IMPORTANT constraints:
- Use `gh-pages-branch: bench-data` (NOT `gh-pages`) -- the existing `docs.yml` uses `actions/deploy-pages` which would conflict
- Use `cancel-in-progress: false` -- interrupted auto-push leaves bench-data in partial state
- The 150% threshold is a locked project decision (STATE.md); do NOT use 110% or 200%
- `auto-push: true` ONLY on the push-to-main and workflow_dispatch steps; PR step must use `auto-push: false` + `save-data-file: false`
- Include `workflow_dispatch` trigger so the workflow can be manually triggered for the initial seed run (the first commits may not touch src/** or include/**)
  </action>
