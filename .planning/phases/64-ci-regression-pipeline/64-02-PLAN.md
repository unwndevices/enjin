  <action>
Create the `bench-data` orphan branch that `github-action-benchmark` will push to:

1. `git checkout --orphan bench-data`
2. `git rm -rf .`
3. `git commit --allow-empty -m "chore: initialize bench-data branch for benchmark history"`
4. `git push origin bench-data`
5. `git checkout main` (return to working branch)
