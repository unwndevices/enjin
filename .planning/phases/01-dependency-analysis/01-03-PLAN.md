<task type="auto">
  <name>Create separate enjin2 CMake target with PRIVATE include directories</name>
  <files>
    enjin2/CMakeLists.txt
  </files>
  <action>
    1. Create enjin2/CMakeLists.txt if it doesn't exist, or update existing:
       - Define enjin2 library target: `add_library(enjin2 STATIC ${ENJIN2_SOURCES})`
       - Set include directories to PRIVATE: `target_include_directories(enjin2 PRIVATE ${CMAKE_CURRENT_SOURCE_DIR}/include/enjin2)`
       - Link external libraries with PRIVATE: `target_link_libraries(enjin2 PRIVATE ${EXTERNAL_LIBRARIES})`
       - Add compiler dependency tracking: `target_compile_options(enjin2 PRIVATE -MMD -MP)`

    2. Ensure strict separation:
       - Do NOT use PUBLIC for enjin2 include directories
       - Do NOT reference enjin1 include paths in enjin2 target
       - Duplicate external library linking (independent linking, not shared)

    3. Example structure:
       ```cmake
       # enjin2/CMakeLists.txt
       cmake_minimum_required(VERSION 3.20)
       project(enjin2 CXX)

       # Enjin2 library target
       add_library(enjin2 STATIC
           src/component.cpp
           src/scene.cpp
           src/engine.cpp
           # ... other enjin2 sources
       )

       # Private include directories (strict isolation)
       target_include_directories(enjin2
           PRIVATE
               $<BUILD_INTERFACE:${CMAKE_CURRENT_SOURCE_DIR}/include/enjin2>
       )

       # Link external libraries independently
       target_link_libraries(enjin2
           PRIVATE
               ${EXTERNAL_LIBRARIES}
       )

       # Enable compiler dependency tracking
       target_compile_options(enjin2 PRIVATE -MMD -MP)
       ```

    4. Verify no enjin1 paths in enjin2 target:
       - Ensure no `include/enjin1` references
       - Ensure no `target_link_libraries(enjin1)` in enjin2 target
       - Ensure all includes are PRIVATE scoped
  </action>
  <verify>
    1. File exists: `test -f enjin2/CMakeLists.txt`
    2. Contains enjin2 target: `grep "add_library(enjin2" enjin2/CMakeLists.txt`
    3. Uses PRIVATE includes: `grep "target_include_directories(enjin2 PRIVATE" enjin2/CMakeLists.txt`
    4. No enjin1 references: `! grep -i "enjin1" enjin2/CMakeLists.txt`
  </verify>
  <done>
    enjin2/CMakeLists.txt exists with enjin2 target using PRIVATE include directories and independent external library linking. No enjin1 references present.
  </done>
