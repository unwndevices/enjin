       - Filter these out from dependency collection

    4. Create structured JSON output at .planning/phases/01-dependency-analysis/dependency-graph.json:
       {
         "metadata": {
           "generated_date": "ISO8601 timestamp",
           "source_analysis": "CMake graphviz + compiler -MMD"
         },
         "dependencies": [
           {
             "source_file": "path/to/enjin2/file.cpp",
             "target_file": "path/to/enjin1/header.h",
             "type": "compile-time|runtime",
             "category": "infrastructure|utilities|feature"
           }
         ]
       }

    5. Categorize dependencies by inspecting file paths:
       - infrastructure: core/, engine/, base/

       - feature: features/, components/, systems/
