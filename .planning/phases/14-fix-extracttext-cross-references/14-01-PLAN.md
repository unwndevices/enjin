  <name>Task 1: Fix extractText() and regenerate all API pages</name>
  <files>scripts/generate-api-docs.js, docs/api/**/*.md</files>
  <action>
In `scripts/generate-api-docs.js`, replace the `extractText()` function (lines 104-115) object branch. Change:

```javascript
if (typeof node === 'object') {
    return Object.values(node).map(extractText).join('');
}
```

To:

```javascript
if (typeof node === 'object') {
    return Object.entries(node)
      .filter(([key]) => key !== '$')
      .map(([, value]) => extractText(value))
      .join('');
}
```

This is a 3-line change. The `$` key is xml2js's convention for storing XML element attributes (refid, kindref, kind). By skipping it, extractText() will only extract actual text content and child elements.

After the fix, regenerate all API pages by running:
```bash
node scripts/generate-api-docs.js
```

This will overwrite all 87 docs/api/**/*.md files with clean text.

Do NOT fix the `const const` duplication issue or add structured parameter formatting — those are out of scope per research recommendations.
