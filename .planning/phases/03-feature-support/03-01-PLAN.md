  <name>Task 1: Add CMake backend selection option to root CMakeLists.txt</name>
  <files>CMakeLists.txt</files>
  <action>
    Add USE_ENJIN1 option to CMakeLists.txt after project() declaration:
    - Add `option(USE_ENJIN1 "Use enjin1 legacy backend" OFF)` below set(CMAKE_CXX_STANDARD_REQUIRED ON)
    - This option defaults to OFF (enjin2 backend)
    - Add message() to show which backend is selected:
      ```
      if(USE_ENJIN1)
          message(STATUS "Building with enjin1 backend")
      else()
          message(STATUS "Building with enjin2 backend")
      endif()
      ```
    - Keep enjin subdirectory commented out (enjin1 not yet integrated with CMake)
    - Do NOT add conditional linking yet - enjin1 will be integrated later
  </action>
  <verify>
    Run `cmake . -DUSE_ENJIN1=OFF` and verify message shows "Building with enjin2 backend"
    Run `cmake . -DUSE_ENJIN1=ON` and verify message shows "Building with enjin1 backend"
  </verify>
  <done>
    USE_ENJIN1 option exists, defaults to OFF, and cmake prints correct backend selection message
  </done>
</task>

<task type="auto">
  <name>Task 2: Update enjin2 CMakeLists.txt with compile definitions</name>
  <files>enjin2/CMakeLists.txt</files>
  <action>
    Add conditional compile definitions to enjin2 target based on USE_ENJIN1 option:
    - Use `target_compile_definitions(enjin2 PRIVATE ...)` to set USE_ENJIN1_BACKEND macro
    - Set USE_ENJIN1_BACKEND=1 when USE_ENJIN1 is ON, USE_ENJIN1_BACKEND=0 when OFF
    - Use CMake generator expression: `$<$<BOOL:${USE_ENJIN1}>:USE_ENJIN1_BACKEND=1:USE_ENJIN1_BACKEND=0>`
    - Or use simpler if() approach:
      ```
      if(USE_ENJIN1)
          target_compile_definitions(enjin2 PRIVATE USE_ENJIN1_BACKEND=1)
      else()
          target_compile_definitions(enjin2 PRIVATE USE_ENJIN1_BACKEND=0)
      endif()
      ```
    - Ensure definitions are PRIVATE (not PUBLIC) to prevent enjin2 dependencies from bleeding into consuming code
  </action>
  <verify>
    Run `cmake . -DUSE_ENJIN1=OFF && cmake --build . --target enjin2`
    Verify build succeeds (enjin2 compiles without enjin1)
    Run `cmake . -DUSE_ENJIN1=ON` and verify compile definitions are set (even though enjin1 linking is stubbed)
  </verify>
  <done>
    enjin2 target has USE_ENJIN1_BACKEND compile definition set correctly for both ON and OFF options
  </done>
</task>
