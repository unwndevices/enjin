  <name>Task 1: Enable full Doxygen warnings</name>
  <files>Doxyfile</files>
  <action>
    Modify Doxyfile to enable comprehensive warning output:

    1. Read current Doxyfile
    2. Set WARN_NO_PARAMDOC=YES to detect missing parameter documentation
    3. Set WARN_IF_UNDOCUMENTED=YES to warn about undocumented public APIs
    4. Set WARN_IF_DOC_ERROR=YES to catch documentation errors
    5. Set QUIET=NO to ensure all warnings are visible
    6. Set WARN_LOGFILE=doxygen-warnings.log to capture warnings to file
    7. Keep EXTRACT_ALL=NO (only document entities with comments - current setting)

    These changes ensure we get complete visibility into all documentation gaps without changing the core behavior of what gets documented.
  </action>
  <verify>
    Run `grep -E "WARN_(NO_PARAMDOC|IF_UNDOCUMENTED|IF_DOC_ERROR|LOGFILE)" Doxyfile` and confirm all are set to YES (or appropriate value).
