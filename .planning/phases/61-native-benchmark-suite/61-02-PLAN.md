   - IMPORTANT: `setActiveScene` clears the event bus. Best approach: do ObjectProxy benchmark first, then event dispatch benchmark (re-subscribe after setActiveScene clears handlers).
3. Add the benchmark:
```cpp
bench.run("lua proxy: find+field round-trip", [&] {
    auto result = eng.executeString("local p = engine.scene.find('bench_target'); local n = p.name");
    ankerl::nanobench::doNotOptimizeAway(result.success);
});
```
This measures the full round-trip: Lua `engine.scene.find` -> C++ `findByName` -> `lua_newuserdata(ObjectProxy)` -> metatable attach -> `setLuaProxy` -> Lua `p.name` -> C++ `__index` metamethod -> `Object::getName()` -> return string to Lua.

**Event dispatch benchmark (BENCH-03 gap closure):**

LuaEventBus is the only dispatch mechanism in enjin2 and lives in the scripting layer (not pure ECS). The benchmark goes in bench_lua.cpp.

After the ObjectProxy benchmark (and after `setActiveScene` was called which clears handlers):
1. Subscribe a Lua callback from C++ side using executeString:
```cpp
// Register a no-op handler for the benchmark event
eng.executeString("engine.event.on('bench_evt', function() end)");
```
2. Add the benchmark:
```cpp
bench.run("lua event: emit dispatch", [&] {
    auto result = eng.executeString("engine.event.emit('bench_evt')");
    ankerl::nanobench::doNotOptimizeAway(result.success);
});
```
This measures: Lua `engine.event.emit` -> C++ `LuaEventBus::emit` -> channel lookup -> snapshot refs -> `lua_rawgeti` + `lua_pcall` for the callback -> return. This is the full event dispatch hot-path.
