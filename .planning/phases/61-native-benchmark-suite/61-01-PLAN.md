- GC pressure: benchmark lua_gc(L, LUA_GCCOLLECT, 0) full collection cycle, doNotOptimizeAway on before/after counts
- CRITICAL: registerAll() is safe with null engine pointers (pointers stored in closures, not dereferenced during registration). Only safe bindings are called (engine.time.delta reads m_timeState value type; math.clamp has no pointer dependency). Do NOT call engine.scene.* or other pointer-dereferencing bindings.
- Write JSON to `bench-results/bench_lua.json`
- Follow the exact Pattern 5 from 61-RESEARCH.md
- After the benchmark block, call eng.shutdown() before JSON write

Add ${LUA_INCLUDE_DIRS} only if needed for headers — enjin2_lua's public include dirs should handle it, but verify during build. If a header-not-found error occurs for lua.h, add `${LUA_INCLUDE_DIRS}` to target_include_directories.
