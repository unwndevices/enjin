**2. Create `src/scripting/bindings_async.cpp`:**

New file implementing all four binding functions plus tickCoroutines and clearCoroutines. Must include `bindings.hpp` and `bindings_internal.hpp`. Follow the existing bindings_debug.cpp pattern for includes and namespace.

Key implementation details from RESEARCH.md:

- `lua_engine_async_start`: Check `luaL_checktype(L, 1, LUA_TFUNCTION)`, find free slot via linear scan, return nil if pool full (NO Lua error — per user decision). Create thread via `lua_newthread(L)`, move function via `lua_pushvalue` + `lua_xmove`, anchor with `luaL_ref`. Set `waitRemaining = 0.0f` (runs on same tick). Return `lua_pushinteger(L, slot.id)`.

- `lua_engine_async_wait`: Guard with `lua_isyieldable(L)` — if not yieldable, push Lua error via `luaL_error`. Get seconds via `luaL_optnumber(L, 1, 0.0)`, clamp negative to 0. Identify calling slot by iterating pool and comparing `lua_tothread` result against `L` parameter. Set `slot.waitRemaining = seconds` BEFORE calling `lua_yield(L, 0)`.

- `lua_engine_async_cancel`: Get cancel ID via `luaL_checkinteger(L, 1)`, scan pool for matching `slot.id`, unref thread with `luaL_unref`, reset slot with `slot = CoroutineSlot{}`.

- `lua_engine_async_cancelAll`: Iterate all slots, unref active threads, reset each slot. Reset `m_nextCoroutineId = 0`.

- `tickCoroutines(dt)`: Get main state via `engine->getState()`. Iterate slots. For active slots: decrement `waitRemaining` by dt. If `waitRemaining > 0.0f`, skip. Otherwise retrieve thread from registry via `lua_rawgeti` + `lua_tothread`, pop from main stack. Resume with lua_resume API compat guard:
  ```cpp
  #if LUA_VERSION_NUM >= 504
      int nres = 0;
      int status = lua_resume(co, L, 0, &nres);
      if (nres > 0) lua_pop(co, nres);
  #else
      int status = lua_resume(co, 0);
      if (lua_gettop(co) > 0) lua_settop(co, 0);
  #endif
  ```
  Handle status: `LUA_YIELD` = coroutine yielded (wait was set before yield, nothing to do). `LUA_OK` = coroutine finished, clear slot. Else = error, print `[async error]` message to stderr, clear slot. Use a private helper `clearSlot(CoroutineSlot& slot, lua_State* L)` that does `luaL_unref` + zero-reset.

- `clearCoroutines()`: Same as cancelAll internal logic — iterate, unref, reset all, reset `m_nextCoroutineId`. Use `engine ? engine->getState() : nullptr` for safety.

- `registerAsyncSubtable(lua_State* L)`: Expects engine table on stack top. Create sub-table with `lua_newtable(L)`, bind the four functions via `luaBindFunctions`, set as "async" field. Follow kCameraFuncs pattern exactly.
