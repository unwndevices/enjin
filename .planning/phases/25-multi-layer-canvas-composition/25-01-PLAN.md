  <action>
Create a new header-only file `include/enjin2/graphics/layer_compositor.hpp` with:

1. `#pragma once` and `#include "canvas.hpp"` (canvas.hpp is in the same directory)
2. `namespace enjin2 {`
3. `constexpr uint8_t ENJIN_LAYER_COUNT = 4;` with `static_assert(ENJIN_LAYER_COUNT >= 1 && ENJIN_LAYER_COUNT <= 8, "ENJIN_LAYER_COUNT must be 1-8");`
4. Template struct `LayerCompositor<uint16_t W, uint16_t H>` containing:
   - `Canvas4<W, H> layers[ENJIN_LAYER_COUNT];` — the layer buffers
   - `Canvas4<W, H> output;` — composited result
   - `bool visible[ENJIN_LAYER_COUNT];` — per-layer visibility (all default to `true` via constructor/initializer)
   - `void clearAll()` — clears layer 0 to Pixel4(0) (black), layers 1..N-1 to Pixel4(15) (transparent)
   - `void composite()` — painter's order compositor:
     - `memcpy(output.getBuffer(), layers[0].getBuffer(), Canvas4<W,H>::BUFFER_SIZE)` to seed output from layer 0 (skip if `!visible[0]`, then seed with all-zero instead via `output.clear(Pixel4(0))`)
     - For layers 1..N-1 where `visible[l]` is true: walk raw PackedPixel4 buffer. For each byte, check low nibble (`src & 0x0F`): if not 0x0F, overwrite output low nibble. Check high nibble (`(src >> 4) & 0x0F`): if not 0x0F, overwrite output high nibble.
     - Use `PackedPixel4` constructor to write back: `out[i] = PackedPixel4(out_byte);`
5. Close namespace.

Performance note: The compositor uses raw buffer walk (not per-pixel getPixel/setPixel) for speed. 128x128 canvas = 8192 bytes per layer, 4 layers = 32768 byte comparisons per frame — trivially fast.

Constructor/initialization: Use `= {}` or a constructor to default all `visible[i] = true`. A simple approach: add a constructor that loops `for (uint8_t i = 0; i < ENJIN_LAYER_COUNT; ++i) visible[i] = true;` — or use `bool visible[ENJIN_LAYER_COUNT] = {true, true, true, true};` if ENJIN_LAYER_COUNT == 4.

The cleanest approach to avoid issues with variable-length aggregate init: provide a constructor:
```cpp
LayerCompositor() {
    for (uint8_t i = 0; i < ENJIN_LAYER_COUNT; ++i) visible[i] = true;
}
```
