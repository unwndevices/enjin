<task type="auto">
  <name>Task 2: Instrument SDL3 runner with measurement sites, --show-timing overlay, and CMake definition</name>
  <files>src/platform/sdl/sdl_main.cpp, CMakeLists.txt</files>
  <action>
    1. **CMakeLists.txt** — Add `ENJIN2_FRAME_TIMING=1` to the `enjin2_sdl` target's existing `target_compile_definitions` block (line 367-371). Add it as an unconditional definition (not gated on Lua). This means every SDL build gets instrumentation. WASM and ESP32 targets do NOT get this definition — the header compiles cleanly without it.

    2. **src/platform/sdl/sdl_main.cpp** — Make these surgical changes:

       **a) Add include** (after existing includes, outside any ifdef):
       ```cpp
       #include <enjin2/instrumentation/frame_timing.hpp>
       ```
       Also add `#include <cstdio>` if not already present (needed for `snprintf`).

       **b) Parse --show-timing** (in main(), after the existing --script parse loop, before SDL_Init):
       ```cpp
       #ifdef ENJIN2_FRAME_TIMING
       bool show_timing = false;
       for (int i = 1; i < argc; i++) {
           if (strcmp(argv[i], "--show-timing") == 0) {
               show_timing = true;
           }
       }
       #endif
       ```

       **c) Cache performance frequency** (after SDL_Init succeeds, inside `#ifdef ENJIN2_FRAME_TIMING`):
       ```cpp
       #ifdef ENJIN2_FRAME_TIMING
       const Uint64 perf_freq = SDL_GetPerformanceFrequency();
       #endif
       ```

       **d) Four measurement sites in the game loop** — all inside `#ifdef ENJIN2_FRAME_TIMING` guards:

       **Site 1 — luaTime_us:** Wrap the entire Lua section (from `if (lua_ok) {` through end of draw pcall). Place `Uint64 t_lua_start = SDL_GetPerformanceCounter();` before the `if (lua_ok)` block inside `#ifdef ENJIN2_BUILD_LUA`, and the store after the draw block closes:
       ```cpp
       #if defined(ENJIN2_FRAME_TIMING) && defined(ENJIN2_BUILD_LUA)
       Uint64 t_lua_start = SDL_GetPerformanceCounter();
       #endif
       // ... existing lua_ok block with input dispatch + update + draw ...
       #if defined(ENJIN2_FRAME_TIMING) && defined(ENJIN2_BUILD_LUA)
       Uint64 t_lua_end = SDL_GetPerformanceCounter();
       enjin2::FrameTimingInstrumentation::get().luaTime_us.store(
           static_cast<uint32_t>((t_lua_end - t_lua_start) * 1000000u / perf_freq),
           std::memory_order_relaxed);
       #endif
       ```

       **Site 2 — updateTime_us:** Inside the `if (lua_ok)` block, wrap the update() pcall + tickCameraFollow + tickCoroutines + tickTweens section (the block in curly braces starting at the `lua_getglobal(lua_L, "update")` line, through `tickTweens(dt)`). Place start before `lua_getglobal(lua_L, "update")` and end after `tickTweens(dt)`:
       ```cpp
       #ifdef ENJIN2_FRAME_TIMING
       Uint64 t_upd_start = SDL_GetPerformanceCounter();
       #endif
       // ... existing update + tick calls ...
       #ifdef ENJIN2_FRAME_TIMING
       Uint64 t_upd_end = SDL_GetPerformanceCounter();
       enjin2::FrameTimingInstrumentation::get().updateTime_us.store(
           static_cast<uint32_t>((t_upd_end - t_upd_start) * 1000000u / perf_freq),
           std::memory_order_relaxed);
       #endif
       ```

       **Site 3 — compositeTime_us:** Wrap `g_compositor.composite()` + `expand_canvas_to_rgb()`:
       ```cpp
       #ifdef ENJIN2_FRAME_TIMING
       Uint64 t_comp_start = SDL_GetPerformanceCounter();
       #endif
       g_compositor.composite();
       expand_canvas_to_rgb();
       #ifdef ENJIN2_FRAME_TIMING
       Uint64 t_comp_end = SDL_GetPerformanceCounter();
       enjin2::FrameTimingInstrumentation::get().compositeTime_us.store(
           static_cast<uint32_t>((t_comp_end - t_comp_start) * 1000000u / perf_freq),
           std::memory_order_relaxed);
       #endif
       ```

       **Site 4 — renderTime_us:** Wrap `SDL_UpdateTexture` + `SDL_RenderClear` + `SDL_RenderTexture` + `SDL_RenderPresent`:
       ```cpp
       #ifdef ENJIN2_FRAME_TIMING
       Uint64 t_rdr_start = SDL_GetPerformanceCounter();
       #endif
       SDL_UpdateTexture(texture, nullptr, g_rgb_staging, CANVAS_W * 3);
       SDL_RenderClear(renderer);
       SDL_RenderTexture(renderer, texture, nullptr, nullptr);
       SDL_RenderPresent(renderer);
       #ifdef ENJIN2_FRAME_TIMING
       Uint64 t_rdr_end = SDL_GetPerformanceCounter();
       enjin2::FrameTimingInstrumentation::get().renderTime_us.store(
           static_cast<uint32_t>((t_rdr_end - t_rdr_start) * 1000000u / perf_freq),
           std::memory_order_relaxed);
       #endif
       ```

       **e) Overlay draw** — After the Lua section ends (after the `#endif` for `ENJIN2_BUILD_LUA`) and BEFORE `g_compositor.composite()`. This is critical: the overlay MUST be drawn after `clearAll()` (which already happened earlier in the loop) and before `composite()`. Use `#ifdef ENJIN2_FRAME_TIMING`:
       ```cpp
       #ifdef ENJIN2_FRAME_TIMING
       if (show_timing) {
           // Draw timing overlay on debug layer (layer 4)
           // getDebugCanvas() works even without ENJIN2_BUILD_LUA because the static
           // LuaCanvas wrapper was created above. But guard with BUILD_LUA since
           // g_lua is only available in that path.
       #ifdef ENJIN2_BUILD_LUA
           LuaCanvas* dbg = g_lua.getBindings().getDebugCanvas();
           if (dbg) {
               auto& ft = enjin2::FrameTimingInstrumentation::get();
               char buf[48];
               snprintf(buf, sizeof(buf), "lua  %4u us",
                        ft.luaTime_us.load(std::memory_order_relaxed));
               dbg->drawText(buf, 1, 1, 8, 1, nullptr);
               snprintf(buf, sizeof(buf), "upd  %4u us",
                        ft.updateTime_us.load(std::memory_order_relaxed));
               dbg->drawText(buf, 1, 10, 8, 1, nullptr);
               snprintf(buf, sizeof(buf), "comp %4u us",
                        ft.compositeTime_us.load(std::memory_order_relaxed));
               dbg->drawText(buf, 1, 19, 8, 1, nullptr);
               snprintf(buf, sizeof(buf), "rdr  %4u us",
                        ft.renderTime_us.load(std::memory_order_relaxed));
               dbg->drawText(buf, 1, 28, 8, 1, nullptr);
           }
       #endif
       }
       #endif
       ```
       Note: The overlay reads from the PREVIOUS frame's timing values for lua/update (since those are stored earlier in the same iteration). composite and render timing will be from the current frame. This one-frame lag for composite/render is acceptable and expected behavior for real-time overlays.

       IMPORTANT: The overlay text is drawn to the debug canvas which is composited on layer 4 (on top of all user layers). It was already cleared by `clearAll()` earlier in the loop. The draw MUST happen before `composite()`.

    3. **Verify no-Lua SDL build still compiles:** The `show_timing` variable and frequency cache are inside `#ifdef ENJIN2_FRAME_TIMING` (always true for SDL), but the overlay draw section is additionally gated with `#ifdef ENJIN2_BUILD_LUA`. The four measurement sites outside the Lua block (composite + render) use only `#ifdef ENJIN2_FRAME_TIMING`. The Lua measurement sites use `#if defined(ENJIN2_FRAME_TIMING) && defined(ENJIN2_BUILD_LUA)`. This ensures clean compilation with or without Lua.
