Create `include/enjin2/scripting/lua_profiler.hpp` as a header-only singleton following the research Pattern 1 exactly. Key implementation details:

1. `#pragma once`, include `lua_platform.hpp` (NOT raw lua.h — lua_platform.hpp provides the correct platform-guarded include), `<cstdint>`, `<cstdio>`, `<cstring>`
2. Namespace `enjin2`
3. `struct LuaProfiler` with:
   - `static constexpr int MAX_FUNCTIONS = 256` and `MAX_NAME_LEN = 64`
   - `struct FuncEntry { const void* ptr; char name[64]; char source[64]; int line; uint32_t callCount; }` — all zero-initialized
   - `FuncEntry entries[MAX_FUNCTIONS]{}; int entryCount{0}; bool active{false};`
   - `static LuaProfiler& get()` — Meyer's singleton (static local)
   - `void reset()` — zero all entries, set entryCount=0, active=false
   - `static void hookCallback(lua_State* L, lua_Debug* ar)` — check `ar->event == LUA_HOOKCALL`, then `lua_getinfo(L, "nSf", ar)` to populate fields, `lua_topointer(L, -1)` for function identity, `lua_pop(L, 1)`, linear scan entries for existing ptr (increment callCount), or add new entry if `entryCount < MAX_FUNCTIONS`. Guard `ar->name` for NULL with `"[?]"` fallback.
   - `void install(lua_State* L)` — `active = true; lua_sethook(L, hookCallback, LUA_MASKCALL, 0);`
   - `void uninstall(lua_State* L)` — `lua_sethook(L, NULL, 0, 0); active = false;` (PROF-03)
   - `void sortByCount()` — insertion sort descending by callCount (256 max entries, O(n^2) is fine)
   - `void printTable()` — `printf` with aligned columns: Function(40), Calls(8), Line(6), Source
   - `void printJSON()` — hand-written JSON array of `{"name","calls","line","source"}` objects to stdout
4. Delete copy constructor and assignment operator
5. Private default constructor

IMPORTANT: The `#include "lua_platform.hpp"` include ensures this header compiles on all platforms (VCV_RACK and ESP32). Do NOT include raw `<lua.h>` directly.
