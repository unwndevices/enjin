Create `src/platform/headless/` directory and `headless_main.cpp` following the research Pattern 3 skeleton. The implementation:

1. **Includes:** `<cstdio>`, `<cstdlib>`, `<cstring>`, `<enjin2/graphics/canvas.hpp>`, `<enjin2/graphics/layer_compositor.hpp>`, `<enjin2/scripting/bindings.hpp>`, `<enjin2/scripting/lua_profiler.hpp>`

2. **Static globals** (same pattern as sdl_main.cpp but without SDL3):
   - `static enjin2::LayerCompositor<ENJIN2_CANVAS_WIDTH, ENJIN2_CANVAS_HEIGHT> g_compositor;`
   - `static enjin2::LuaScriptSystem g_lua;`
   - 5 static `enjin2::LuaCanvas` wrappers: `g_lua_layer0` through `g_lua_layer4` pointing to `g_compositor.layers[0..4]`
   - `static enjin2::LuaCanvas* g_lua_layers[4] = { &g_lua_layer0, &g_lua_layer1, &g_lua_layer2, &g_lua_layer3 };`

3. **Arg parsing in main():**
   - `--profile` -> `bool do_profile = true`
   - `--frames N` -> `int frames = N` (default 100)
   - `--output json` -> `bool output_json = true`
   - Positional `script.lua` -> `const char* script`
   - Print usage and return 1 if no script provided

4. **Initialization:**
   - `g_lua.initialize()` — check return, fprintf error + return 1 on failure
   - `g_lua.getBindings().setLayers(g_lua_layers, 4, g_compositor.visible)` — CRITICAL: prevents null canvas dereference in draw calls
   - `g_lua.getBindings().setDebugCanvas(&g_lua_layer4)` — wire debug layer
   - Do NOT call `setInput()` — leave `currentInput` as nullptr; all `engine.input.*` bindings null-guard safely

5. **Profiler wiring (BEFORE loadScript so init() calls are counted):**
   - If `do_profile`: `LuaProfiler::get().reset(); LuaProfiler::get().install(g_lua.getEngine().getState());`
   - If NOT `do_profile`: `lua_sethook(g_lua.getEngine().getState(), NULL, 0, 0);` (PROF-03 explicit confirmation)

6. **Script loading:**
   - `g_lua.loadScript(script)` — check LuaResult success, fprintf error + shutdown + return 1 on failure

7. **Headless frame loop** (mirrors sdl_main.cpp lines 302-387):
   - `float dt = 1.0f / 60.0f; float totalTime = 0.0f; uint32_t frameCount = 0;`
   - GC ring buffer: `static constexpr int GC_RING = 256; int32_t gcDeltas[GC_RING]{}; int gcHead = 0;`
   - `lua_State* L = g_lua.getEngine().getState();`
   - For `f = 0..frames-1`:
     a. `totalTime += dt; g_lua.getBindings().setTimeState(dt, totalTime, frameCount++);`
     b. GC snapshot before: `int mem_before = lua_gc(L, LUA_GCCOUNT, 0) * 1024 + lua_gc(L, LUA_GCCOUNTB, 0);`
     c. Call `update()`: `lua_getglobal(L, "update"); if (lua_isfunction(L, -1)) { lua_pushnil(L); lua_pushnumber(L, dt); if (lua_pcall(L, 2, 0, 0) != LUA_OK) { fprintf error, lua_pop, break; } } else { lua_pop(L, 1); }`
     d. Tick subsystems: `g_lua.getBindings().tickCameraFollow(dt); tickCoroutines(dt); tickTweens(dt);`
     e. Call `draw()`: `lua_getglobal(L, "draw"); if (lua_isfunction(L, -1)) { lua_pushnil(L); if (lua_pcall(L, 1, 0, 0) != LUA_OK) { fprintf error, lua_pop, break; } } else { lua_pop(L, 1); }`
     f. GC snapshot after: compute delta, store in `gcDeltas[gcHead++]` if `gcHead < GC_RING`

8. **Cleanup and output:**
   - If `do_profile`: `LuaProfiler::get().uninstall(L);` BEFORE shutdown (prevents hook firing during lua_close GC sweep)
   - `g_lua.shutdown();`
   - If `do_profile`:
     - If `output_json`: `LuaProfiler::get().printJSON();`
     - Else: `LuaProfiler::get().printTable();` then print GC pressure summary (min/max/avg delta over gcHead frames)
   - `return 0;`

  <name>Task 2: Add ENJIN2_BUILD_HEADLESS CMake option and enjin_run target</name>
  <files>CMakeLists.txt</files>
  <action>
Add the headless runner CMake target to the root `CMakeLists.txt`. Place it AFTER the `if(ENJIN2_BUILD_SDL)` block and BEFORE `if(ENJIN2_BUILD_BENCHMARKS)`.

```cmake
# Headless Lua runner for profiling (PROF-04..PROF-06)
option(ENJIN2_BUILD_HEADLESS "Build headless Lua profiling runner (enjin_run)" OFF)

if(ENJIN2_BUILD_HEADLESS)
    if(EMSCRIPTEN OR ESP32)
        message(FATAL_ERROR "ENJIN2_BUILD_HEADLESS is not supported on WASM or ESP32 targets")
    endif()
    if(NOT TARGET enjin2_lua)
        message(FATAL_ERROR "ENJIN2_BUILD_HEADLESS requires ENJIN2_BUILD_LUA=ON")
    endif()
    add_executable(enjin_run
        src/platform/headless/headless_main.cpp
    )
    target_include_directories(enjin_run PRIVATE
        $<BUILD_INTERFACE:${CMAKE_CURRENT_SOURCE_DIR}/include>
        ${LUA_INCLUDE_DIRS}
    )
    target_link_libraries(enjin_run PRIVATE
        enjin2_core
        enjin2_graphics
        enjin2_ui
        enjin2_input
        enjin2_lua
    )
    target_compile_definitions(enjin_run PRIVATE
        ENJIN2_BUILD_LUA=1
        ENJIN2_CANVAS_WIDTH=${ENJIN2_CANVAS_WIDTH}
        ENJIN2_CANVAS_HEIGHT=${ENJIN2_CANVAS_HEIGHT}
    )
endif()
```

Key details:
- `ENJIN2_BUILD_HEADLESS` defaults OFF (same pattern as ENJIN2_BUILD_SDL)
- FATAL_ERROR guards for EMSCRIPTEN/ESP32 (same pattern as benchmark targets)
- FATAL_ERROR if enjin2_lua target does not exist (requires ENJIN2_BUILD_LUA=ON)
- Links same libraries as enjin2_sdl MINUS SDL3
- Defines ENJIN2_BUILD_LUA=1 and ENJIN2_CANVAS_WIDTH/HEIGHT for canvas template instantiation
- No ENJIN2_FRAME_TIMING define (headless runner does not use frame timing atomics)
