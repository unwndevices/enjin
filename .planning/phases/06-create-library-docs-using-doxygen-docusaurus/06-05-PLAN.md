<task type="auto">
  <name>Create GitHub Actions workflow for documentation deployment</name>
  <files>.github/workflows/docs.yml</files>
  <action>
    1. Create .github/workflows/ directory if it doesn't exist
    2. Create .github/workflows/docs.yml with the following content:
       name: Deploy Documentation

       on:
         push:
           branches: [main]
         pull_request:

       jobs:
         deploy:
           runs-on: ubuntu-latest

           steps:
             - name: Checkout repository
               uses: actions/checkout@v3

             - name: Setup Node.js
               uses: actions/setup-node@v3
               with:
                 node-version: 18
                 cache: 'npm'
                 cache-dependency-path: 'docs/package-lock.json'

             - name: Install Doxygen
               run: |
                 sudo apt-get update
                 sudo apt-get install -y doxygen graphviz

             - name: Build doxygen XML
               run: |
                 doxygen docs/Doxyfile

             - name: Install dependencies
               run: cd docs && npm ci

             - name: Build Docusaurus site
               run: cd docs && npm run build

             - name: Deploy to GitHub Pages
               uses: peaceiris/actions-gh-pages@v3
               if: github.ref == 'refs/heads/main'
               with:
                 github_token: ${{ secrets.GITHUB_TOKEN }}
                 publish_dir: ./docs/build

     Reference: .planning/phases/06-create-library-docs-using-doxygen-docusaurus/06-RESEARCH.md (GitHub Actions Workflow section)

     Note:
     - Workflow runs on every push to main branch
     - Pull requests build docs but don't deploy
     - Deployment only happens on main branch (if: github.ref == 'refs/heads/main')
     - Uses Node.js 18 for Docusaurus build
     - Installs doxygen and graphviz for XML generation
     - Deploys docs/build directory to gh-pages branch
  </action>
  <verify>test -f .github/workflows/docs.yml && grep -q "Deploy Documentation" .github/workflows/docs.yml</verify>
  <done>GitHub Actions workflow file created for automated documentation deployment</done>
</task>
