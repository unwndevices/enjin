Create `include/enjin2/graphics/palette.hpp` in `namespace enjin2`:

1. **RGB struct** — `uint8_t r, g, b` with `constexpr` default and 3-arg constructors.

2. **Constants:**
   - `constexpr uint8_t PALETTE_TRANSPARENT = 15;`
   - `constexpr uint8_t PALETTE_MAX_ENTRIES = 15;` (indices 0-14)

3. **Palette struct** with:
   - `RGB colors[PALETTE_MAX_ENTRIES];` — indices 0-14
   - `uint8_t size;` — preset-defined count for wrapping
   - `bool debugTransparent;` — runtime flag for magenta debug mode (default false)
   - `Palette();` — default constructor initializes to PICO-8 palette
   - `void setColor(uint8_t index, uint8_t r, uint8_t g, uint8_t b);` — wraps index via `index % size` if `index >= PALETTE_TRANSPARENT`
   - `RGB getColor(uint8_t index) const;` — wraps similarly
   - `RGB resolve(uint8_t index) const;` — caller must check `isTransparent()` first; wraps `index % size`
   - `bool isTransparent(uint8_t index) const;` — returns `index == PALETTE_TRANSPARENT`
   - `bool loadPreset(const char* name);` — replaces palette from named preset table
   - `uint8_t getSize() const;`

4. **`parseHexColor` free function:**
   - `bool parseHexColor(const char* hex, uint8_t& r, uint8_t& g, uint8_t& b);`
   - Handles optional leading `#`, uses `sscanf(start, "%02hhx%02hhx%02hhx", &r, &g, &b)`

5. **Global instance:** `extern Palette g_palette;`

6. **Doxygen comments** on all public symbols following project conventions (`/** @brief ... */`).

Create `src/graphics/palette.cpp`:

1. `#include "../../include/enjin2/graphics/palette.hpp"` plus `<cstring>` and `<cstdio>`
2. `Palette g_palette;` — single engine-level instance
3. `static constexpr RGB DEFAULT_COLORS[15]` — the exact PICO-8 colors from CONTEXT.md:
   - 0:`#1a1c2c`, 1:`#5d275d`, 2:`#b13e53`, 3:`#ef7d57`, 4:`#ffcd75`, 5:`#a7f070`, 6:`#38b764`, 7:`#257179`, 8:`#29366f`, 9:`#3b5dc9`, 10:`#41a6f6`, 11:`#73eff7`, 12:`#f4f4f4`, 13:`#566c86`, 14:`#333c57`

5. `PalettePreset` struct with `const char* name`, `const RGB* colors`, `uint8_t size`
6. Static `PRESETS[]` array with `{"default", DEFAULT_COLORS, 15}`, `{"gameboy", GAMEBOY_COLORS, 4}`

**Test cases:**

a. **Default palette initialization:**
   - `g_palette.getSize() == 15`
   - `g_palette.getColor(0)` returns `RGB{0x1a, 0x1c, 0x2c}` (dark navy)
   - `g_palette.getColor(12)` returns `RGB{0xf4, 0xf4, 0xf4}` (white)
   - `g_palette.getColor(14)` returns `RGB{0x33, 0x3c, 0x57}` (dark slate)

b. **Transparency:**
   - `g_palette.isTransparent(15) == true`
   - `g_palette.isTransparent(0) == false`
   - `g_palette.isTransparent(14) == false`

c. **setColor / getColor:**
   - `g_palette.setColor(0, 255, 0, 0)` then `getColor(0)` returns `{255, 0, 0}`
   - Restore with `g_palette.loadPreset("default")`

d. **Wrapping:**
   - Load gameboy preset (size=4)
   - `g_palette.getColor(5)` should return same as `getColor(1)` (5 % 4 = 1)
   - `g_palette.isTransparent(15) == true` — transparency survives wrapping

e. **Transparency before modulo (Pitfall 4):**
   - With gameboy loaded (size=4), verify `isTransparent(15) == true` (not resolving to index 3 via 15%4)

f. **loadPreset:**
   - `g_palette.loadPreset("gameboy")` returns true, size becomes 4
   - `g_palette.loadPreset("default")` returns true, size becomes 15
   - `g_palette.loadPreset("nonexistent")` returns false

g. **parseHexColor:**
   - `parseHexColor("#ff0000", r, g, b)` sets r=255, g=0, b=0
   - `parseHexColor("00ff00", r, g, b)` sets r=0, g=255, b=0 (no `#`)
   - `parseHexColor("#FF00ff", r, g, b)` works (mixed case)
   - `parseHexColor(nullptr, r, g, b)` returns false

Print pass/fail summary. Return 0 if all pass, 1 otherwise.
