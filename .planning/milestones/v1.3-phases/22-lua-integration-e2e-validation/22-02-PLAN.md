**CMakeLists.txt changes (enjin2_sdl block, lines ~268-279):**

Replace the current `target_link_libraries` and `target_include_directories` blocks for `enjin2_sdl` with versions that conditionally add Lua support:

```cmake
target_include_directories(enjin2_sdl PRIVATE
    $<BUILD_INTERFACE:${CMAKE_CURRENT_SOURCE_DIR}/include>
    $<$<BOOL:${ENJIN2_BUILD_LUA}>:${LUA_INCLUDE_DIRS}>
)
target_link_libraries(enjin2_sdl PRIVATE
    enjin2_core
    enjin2_graphics
    enjin2_input
    $<$<BOOL:${ENJIN2_BUILD_LUA}>:enjin2_lua>
    SDL3::SDL3
)
target_compile_definitions(enjin2_sdl PRIVATE
    $<$<BOOL:${ENJIN2_BUILD_LUA}>:ENJIN2_BUILD_LUA=1>
)
```

The `$<$<BOOL:${ENJIN2_BUILD_LUA}>:...>` generator expression ensures:
- With `ENJIN2_BUILD_LUA=OFF`: enjin2_sdl builds without any Lua dependency. No link errors, no include failures.
- With `ENJIN2_BUILD_LUA=ON`: enjin2_lua is linked and ENJIN2_BUILD_LUA=1 is defined so #ifdef guards in sdl_main.cpp activate.

Note: `${LUA_INCLUDE_DIRS}` is already populated by the existing `find_package(Lua)` call in the ENJIN2_BUILD_LUA block earlier in CMakeLists.txt. No new find_package call needed.

**sdl_main.cpp changes:**

1. Add Lua includes wrapped in `#ifdef ENJIN2_BUILD_LUA` after the existing includes:
   ```cpp
   #ifdef ENJIN2_BUILD_LUA
   #include <enjin2/scripting/bindings.hpp>
   #include <iostream>
   #endif
   ```

2. Add Lua static globals after `g_rgb_staging`, wrapped in `#ifdef`:
   ```cpp
   #ifdef ENJIN2_BUILD_LUA
   static enjin2::LuaScriptSystem g_lua;
   static enjin2::LuaCanvas       g_lua_canvas(&g_canvas);
   #endif
   ```

3. **Remove the `draw_palette_grid()` function definition entirely** (the static function at lines ~95-117). It was a Phase 21 debug aid, now superseded by the Lua color grid drawn directly on the canvas. This eliminates the Pitfall 5 overlap issue.

4. In `main()`, after SDL init succeeds and before the game loop (`// --- Game loop ---`), add Lua initialization wrapped in `#ifdef`:
   ```cpp
   #ifdef ENJIN2_BUILD_LUA
   if (!g_lua.initialize()) {
       SDL_Log("Lua init failed");
       SDL_DestroyTexture(texture);
       SDL_DestroyRenderer(renderer);
       SDL_DestroyWindow(window);
       SDL_Quit();
       return 1;
   }
   g_lua.setCanvas(&g_lua_canvas);
   g_lua.getBindings().setInput(&g_input);
   {
       enjin2::LuaResult load_result = g_lua.loadScript("scripts/e2e_parity.lua");
       if (!load_result.success) {
           std::cerr << "Lua script load error: " << load_result.error << "\n";
           g_canvas.clear(enjin2::Pixel4(14));
       }
   }
   #endif
   ```

5. Inside the game loop, after `input_platform_poll(&g_input)` and before `expand_canvas_to_rgb()`, add Lua per-frame calls wrapped in `#ifdef`:
   ```cpp
   #ifdef ENJIN2_BUILD_LUA
   g_lua.getBindings().setInput(&g_input);  // wire current-frame input AFTER poll
   {
       enjin2::LuaResult r = g_lua.callFunction("update", dt);
       if (!r.success) {
           std::cerr << "Lua update error: " << r.error << "\n";
           g_canvas.clear(enjin2::Pixel4(14));
       }
   }
   {
       enjin2::LuaResult r = g_lua.callFunction("draw");
       if (!r.success) {
           std::cerr << "Lua draw error: " << r.error << "\n";
           g_canvas.clear(enjin2::Pixel4(14));
       }
   }
   #endif
   ```
   Note: `dt` is the delta-time float value that must be computed before this block. Read the existing game loop to confirm where `dt` is computed; if it is not yet computed at this point, compute it here: `float dt = static_cast<float>(SDL_GetTicks() - frame_start) / 1000.0f;` and clamp: `if (dt > max_dt) dt = max_dt;`. Remove the `(void)max_dt;` that suppressed the unused warning in Phase 21.

6. **Remove the `draw_palette_grid(renderer);` call** inside the render block (line ~213 currently). The function is being deleted; this call must also go.

7. At the end of `main()`, before SDL_DestroyTexture, add Lua shutdown wrapped in `#ifdef`:
   ```cpp
   #ifdef ENJIN2_BUILD_LUA
   g_lua.shutdown();
   #endif
   ```

**Frame loop ordering (CRITICAL — must follow this exact order per Phase 21 + research decisions):**
```
input_advance_frame(&g_input)     // clears current, snapshots prev
input_platform_poll(&g_input)     // writes current frame's keys
[#ifdef] setInput(&g_input)       // wire to bindings AFTER poll
[#ifdef] callFunction("update")   // script sees current-frame input
[#ifdef] callFunction("draw")     // script draws to canvas
expand_canvas_to_rgb()            // expand canvas AFTER Lua has drawn
SDL_UpdateTexture(...)
SDL_RenderClear(...)
SDL_RenderTexture(...)
// draw_palette_grid REMOVED
SDL_RenderPresent(...)
```
