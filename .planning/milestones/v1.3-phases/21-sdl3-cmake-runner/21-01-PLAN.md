  <action>
Append the following block to the END of `CMakeLists.txt` (after the `if(ENJIN2_BUILD_EXAMPLES)` block):

```cmake
# SDL3 desktop runner
option(ENJIN2_BUILD_SDL "Build SDL3 desktop runner executable (requires internet on first configure)" OFF)

if(ENJIN2_BUILD_SDL)
    include(FetchContent)
    FetchContent_Declare(
        SDL3
        GIT_REPOSITORY https://github.com/libsdl-org/SDL.git
        GIT_TAG        release-3.4.2
        GIT_SHALLOW    TRUE
        EXCLUDE_FROM_ALL
    )
    FetchContent_MakeAvailable(SDL3)
    # FetchContent_MakeAvailable will fail CMake configure if download fails — no fallback needed

    add_executable(enjin2_sdl
        src/platform/sdl/sdl_main.cpp
    )
    target_include_directories(enjin2_sdl PRIVATE
        $<BUILD_INTERFACE:${CMAKE_CURRENT_SOURCE_DIR}/include>
    )
    target_link_libraries(enjin2_sdl PRIVATE
        enjin2_core
        enjin2_graphics
        enjin2_input
        SDL3::SDL3
    )
endif()
```

CRITICAL rules:
- Do NOT add `enjin2_lua` or the aggregate `enjin2` INTERFACE target to target_link_libraries — only the three component libs + SDL3::SDL3. This prevents Lua from being a transitive SDL dependency.
- Do NOT touch the existing ENJIN2_BUILD_WASM block, the EMSCRIPTEN guard, or any existing target.
- Do NOT add `SDL3::SDL3` to any existing target (enjin2_core, enjin2_graphics, enjin2_input, enjin2_lua, enjin2).
- The `EXCLUDE_FROM_ALL` on FetchContent_Declare prevents SDL3 install rules from bleeding into the project's install target.
- `GIT_TAG release-3.4.2` pins to the latest stable SDL3 as of 2026-02-21. Use exactly this tag string.
