**input_platform_poll definition (inside `namespace enjin2`):**

This is the Phase 20 platform hook. Phase 20 declared it but intentionally left it undefined. This SDL3 file is the ONLY place it may be defined. Use `SDL_GetKeyboardState` (not SDL_EVENT_KEY_DOWN) for held-key detection. WASD mirrors arrows to the same button bits.

```cpp
namespace enjin2 {
void input_platform_poll(InputState* state) {
    const bool* keys = SDL_GetKeyboardState(nullptr);
    auto set_btn = [&](int btn, bool on) {
        if (on) state->buttons |= static_cast<uint16_t>(1u << btn);
    };
    set_btn(BTN_UP,    keys[SDL_SCANCODE_UP]    || keys[SDL_SCANCODE_W]);
    set_btn(BTN_DOWN,  keys[SDL_SCANCODE_DOWN]  || keys[SDL_SCANCODE_S]);
    set_btn(BTN_LEFT,  keys[SDL_SCANCODE_LEFT]  || keys[SDL_SCANCODE_A]);
    set_btn(BTN_RIGHT, keys[SDL_SCANCODE_RIGHT] || keys[SDL_SCANCODE_D]);
    set_btn(BTN_A,     keys[SDL_SCANCODE_Z]);
    set_btn(BTN_B,     keys[SDL_SCANCODE_X]);
    set_btn(BTN_START, keys[SDL_SCANCODE_RETURN]);
}
} // namespace enjin2
```

**Canvas expand helper:**

```cpp
static void expand_canvas_to_rgb() {
    for (int y = 0; y < CANVAS_H; y++) {
        for (int x = 0; x < CANVAS_W; x++) {
            enjin2::Pixel4 px = g_canvas.getPixel(x, y);
            int i = (y * CANVAS_W + x) * 3;
            if (!enjin2::g_palette.isTransparent(px.value)) {
                enjin2::RGB rgb = enjin2::g_palette.resolve(px.value);
                g_rgb_staging[i + 0] = rgb.r;
                g_rgb_staging[i + 1] = rgb.g;
                g_rgb_staging[i + 2] = rgb.b;
            } else {
                g_rgb_staging[i + 0] = 0;
                g_rgb_staging[i + 1] = 0;
                g_rgb_staging[i + 2] = 0;
            }
        }
    }
}
```

**main() — parse `--fps N`, SDL init, window + renderer, texture, game loop, shutdown:**

Key implementation points for `main()`:
- Parse `--fps N` from argv using a simple loop (see RESEARCH.md Pattern 6). Clamp to `1..300`, default 30.
- `SDL_Init(SDL_INIT_VIDEO)` — returns `true` on SDL3 success (SDL3 changed return type). Check with `if (!SDL_Init(...))`.
- `SDL_CreateWindowAndRenderer("Enjin2", WIN_W, WIN_H, 0, &window, &renderer)` — `0` flags = no SDL_WINDOW_RESIZABLE (fixed size, pixel-perfect).
- `SDL_CreateTexture(renderer, SDL_PIXELFORMAT_RGB24, SDL_TEXTUREACCESS_STREAMING, CANVAS_W, CANVAS_H)`
- `SDL_SetTextureScaleMode(texture, SDL_SCALEMODE_NEAREST)` — MUST be set immediately after texture creation. SDL3 defaults to bilinear; failing to set this causes blurry pixels.
- `SDL_SetRenderScale(renderer, static_cast<float>(DEFAULT_SCALE), static_cast<float>(DEFAULT_SCALE))` — do NOT use SDL_SetRenderLogicalPresentation (confirmed SDL3 bug #11335 ignores scale mode).
- Timer: `Uint64 last_ticks = SDL_GetTicks()` — use `SDL_GetTicks()` (returns Uint64 in SDL3; SDL_GetTicks64 was removed).
- Delta-time clamping: `const float max_dt = 4.0f / static_cast<float>(fps)` — 4-frame ceiling.
- Frame pacing: `SDL_Delay(static_cast<Uint32>(frame_ms - elapsed))` when elapsed < frame_ms.
- Event loop: drain ALL events first with `while (SDL_PollEvent(&event))`, THEN call `SDL_GetKeyboardState`. Key-repeat via SDL_EVENT_KEY_DOWN has OS delay (~1s) — always use GetKeyboardState for held detection.
- Escape handling: `SDL_EVENT_KEY_DOWN` with `event.key.key == SDLK_ESCAPE` → `running = false`. Escape is NOT mapped to any InputState button.
- Input order: `input_advance_frame(&g_input)` BEFORE `enjin2::input_platform_poll(&g_input)` — advance clears current, poll writes to current. Reversing this order causes all inputs to appear as justReleased every frame.
- Render: `SDL_UpdateTexture(texture, nullptr, g_rgb_staging, CANVAS_W * 3)` — pitch is `CANVAS_W * 3` for RGB24 (3 bytes/pixel, NOT 4).
- Shutdown: `SDL_DestroyTexture`, `SDL_DestroyRenderer`, `SDL_DestroyWindow`, `SDL_Quit()` — all called on clean exit and on any early-return error path.
- The canvas is zero-initialized on construction (all pixels = index 0, which maps to the first default palette color). No test pattern, no fake content — blank canvas with default palette as required.
