## Tech Debt

### Phase 42: EventBus

- **Observation (low severity):** `setActiveScene()` calls `clearHandlers()` which sets `m_L=nullptr`, but does not immediately re-arm the bus via `setLuaState(L)`. The bus is re-armed by the next `loadScript()` / `loadScriptFile()` call. This creates a narrow window where direct C++ calls to `bus.subscribe()` would silently fail (returning 0). Safe in all Lua-reachable paths since Lua code only executes after a script is loaded. One-line fix available if needed: add `m_eventBus.setLuaState(engine->getState())` after `clearHandlers()` in `setActiveScene()`.

### Pre-Existing Issues (Resolved)

- `sprite_load_test` — pre-existing CMake failure from missing GTest dependency. Fixed in Phase 42 with `find_package(GTest QUIET)` guard. Not a v1.6 regression.
