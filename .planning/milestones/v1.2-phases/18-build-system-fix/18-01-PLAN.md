<objective>
Fix the WASM build path to work correctly when Lua is disabled (`ENJIN2_BUILD_LUA=OFF`).

Purpose: The WASM block in CMakeLists.txt unconditionally links `enjin2_lua` and includes `luajit/src`, and `emscripten_bindings.cpp` unconditionally includes Lua headers. When `ENJIN2_BUILD_LUA=OFF`, the `enjin2_lua` target does not exist, causing a CMake configuration failure. This plan guards both the CMake directives and the C++ source with conditional checks.

Output: Two modified files that allow `ENJIN2_BUILD_WASM=ON` with `ENJIN2_BUILD_LUA=OFF` while preserving full functionality when both are ON.
</objective>
