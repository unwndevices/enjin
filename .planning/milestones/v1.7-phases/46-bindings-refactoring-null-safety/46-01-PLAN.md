**Step 1: Create `src/scripting/bindings_internal.hpp`**

This is a PRIVATE header (in src/, NOT in include/). It holds metatable name constants shared between bindings.cpp and bindings_proxy.cpp.

Contents:
```cpp
// src/scripting/bindings_internal.hpp
// Private inter-TU declarations for enjin2_lua — NOT a public install header
#pragma once
#include "../../include/enjin2/scripting/bindings.hpp"
#include "../../include/enjin2/scripting/component_proxy.hpp"

namespace enjin2 {

// Metatable name constants — shared by bindings.cpp and bindings_proxy.cpp
static constexpr const char* PROXY_METATABLE           = "ScriptProxy";
static constexpr const char* CPOSITION_PROXY_METATABLE = "C_Position_Proxy";
static constexpr const char* CTIMER_PROXY_METATABLE    = "C_Timer_Proxy";
static constexpr const char* CFSM_PROXY_METATABLE      = "C_StateMachine_Proxy";
static constexpr const char* CTILEMAP_PROXY_METATABLE  = "C_Tilemap_Proxy";
static constexpr const char* CCAMERA_PROXY_METATABLE   = "C_Camera_Proxy";
static constexpr const char* OBJECT_PROXY_METATABLE    = "ObjectProxy";

} // namespace enjin2
```

CRITICAL: Use `static constexpr` — these are TU-local constants, no ODR issue. Do NOT put g_currentBindings here (it is a non-const global; putting it here would create an ODR violation with one definition per TU).

**Step 2: Create `src/scripting/bindings_proxy.cpp`**

- Lines 1204-1338: ObjectProxy metatable (`static int lua_object_proxy_*_impl()` functions)
- Lines 1339-1377: `LuaBindings::registerObjectProxyMetatable()` and `LuaBindings::registerComponentProxyMetatable()` member function definitions

The file must include:

```cpp
#include "../../include/enjin2/components/lua_script.hpp"

```

After extraction, remove the per-file `static constexpr const char* CPOSITION_PROXY_METATABLE` etc. definitions from the extracted code — use the constants from bindings_internal.hpp instead. The ObjectProxy metatable name string (currently a literal in the code) must also use the `OBJECT_PROXY_METATABLE` constant from the header.

IMPORTANT: The `registerObjectProxyMetatable()` and `registerComponentProxyMetatable()` functions call the static `lua_object_proxy_*_impl` and `lua_c*_proxy_index_impl` functions. These static functions MUST be in the SAME translation unit (bindings_proxy.cpp) as the register functions that reference them. Static functions have internal linkage — they cannot be called from another TU.
