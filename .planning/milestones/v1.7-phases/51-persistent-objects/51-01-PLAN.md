**ObjectCollection (object_collection.hpp) — add three things:**

1. `extractObject(Object* obj)` — returns `std::unique_ptr<Object>` by scanning `objects[]` for matching raw pointer, moving the unique_ptr out, shifting remaining elements left, decrementing objectCount. Returns nullptr if not found. This is like `removeObject()` but returns the unique_ptr instead of letting it drop (which would destroy the object and invalidate its proxy).

2. `m_external[]` non-owning injection array:
   - Private members: `static constexpr size_t MAX_EXTERNAL = 4;`, `Object* m_external[MAX_EXTERNAL]{};`, `size_t m_externalCount{0};`
   - Public `injectExternal(Object* obj)` — adds to m_external if m_externalCount < MAX_EXTERNAL and obj != nullptr
   - Public `clearExternal()` — zeros all m_external slots, resets m_externalCount to 0

3. Extend existing methods to also iterate externals AFTER owned objects:
   - `update(float dt)` — after owned loop, add loop over m_external[0..m_externalCount-1] calling update(dt) on active externals
   - `lateUpdate(float dt)` — same pattern, iterate externals after owned
   - `findByName(const char* name)` — after owned search, search externals (return first match)
   - `forEach(std::function<void(Object*)> func)` — after owned loop, iterate externals
   - `forEachActive(std::function<void(Object*)> func)` — after owned loop, iterate active externals
   - `findAllWithTag(...)` — after owned loop, continue searching externals
   - `clear()` does NOT clear externals (externals are managed by registry via clearExternal())
   - `size()` returns objectCount only (externals are not "owned")

**SceneStateMachine (scene_state_machine.hpp) — add PersistentObjectRegistry:**

1. Define `PersistentObjectRegistry` struct inside the class (or as a nested struct):
   ```cpp
   struct PersistentObjectRegistry {
       static constexpr int MAX_PERSISTENT = 4;
       std::unique_ptr<Object> objects[MAX_PERSISTENT];
       bool pendingRemoval[MAX_PERSISTENT]{};

       bool add(std::unique_ptr<Object> obj);       // find empty slot, move in, return true; false if full
       void markForRemoval(Object* obj);             // set pendingRemoval flag for matching object
       bool contains(Object* obj) const;             // check if object is already in registry (prevent double-add)
       Object* findByName(const char* name) const;   // search non-removed objects by name
       void flushPendingRemovals();                  // reset unique_ptrs for slots marked pendingRemoval
   };
   ```
   - `add()`: scan for first nullptr slot, move unique_ptr in, clear pendingRemoval for that slot, return true. If no empty slot, return false.
   - `markForRemoval()`: scan for matching raw pointer, set pendingRemoval[i] = true.
   - `contains()`: scan for matching raw pointer (non-null), return true if found.
   - `findByName()`: scan non-null, non-pendingRemoval objects, strcmp on getName().
   - `flushPendingRemovals()`: for each slot where pendingRemoval is true, reset the unique_ptr (this destroys the object and invalidates its proxy), clear pendingRemoval flag.

2. Add private member `PersistentObjectRegistry m_persistentRegistry;`

3. Add public methods:
   - `bool persistObject(Object* obj)` — calls `currentScene->getObjects().extractObject(obj)` to get unique_ptr, then `m_persistentRegistry.add(std::move(extracted))`. Returns false if object not found in current scene OR registry is full. Also check `m_persistentRegistry.contains(obj)` first — if already persistent, return true (silent no-op).
   - `void unpersistObject(Object* obj)` — calls `m_persistentRegistry.markForRemoval(obj)`
   - `Object* findPersistentByName(const char* name) const` — delegates to `m_persistentRegistry.findByName(name)`

4. Modify `applyDeferredTransition(uint32_t targetId)`:

   **Self-transition path (isSelf == true):**
   ```
   m_persistentRegistry.flushPendingRemovals();
   scene->getObjects().clearExternal();
   scene->deactivate();
   scene->resetInitialized();
   scene->setStateMachine(this);
   // Re-inject surviving persistent objects
   for (int i = 0; i < PersistentObjectRegistry::MAX_PERSISTENT; ++i) {
       if (m_persistentRegistry.objects[i]) {
           scene->getObjects().injectExternal(m_persistentRegistry.objects[i].get());
       }
   }
   scene->activate();
   ```

   **Cross-scene path (isSelf == false):**
   ```
   m_persistentRegistry.flushPendingRemovals();
   if (currentScene) {
       currentScene->getObjects().clearExternal();
       currentScene->deactivate();
   }
   Scene* oldScene = currentScene;
   currentScene = targetScene;
   currentScene->setStateMachine(this);
   // Inject persistent objects into new scene
   for (int i = 0; i < PersistentObjectRegistry::MAX_PERSISTENT; ++i) {
       if (m_persistentRegistry.objects[i]) {
           currentScene->getObjects().injectExternal(m_persistentRegistry.objects[i].get());
       }
   }
   if (!currentScene->isInitialized()) { currentScene->initialize(); }
   if (!currentScene->isActive()) { currentScene->activate(); }
   onSceneChangeCompleteSignal.emit(oldScene, currentScene);
   ```

   Note: The oldScene variable must be captured BEFORE changing currentScene in the cross-scene path. The existing code already does this pattern but the variable name differs — adapt accordingly.
