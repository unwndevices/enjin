Implement four functions as static int member functions of LuaBindings:

- **lua_engine_ui_progressBar(L)**: Extract x(int16), y(int16), w(uint16), h(uint16), value(float via luaL_checknumber), fg(uint8), bg(uint8). Clamp value to [0,1]. fillRect(x,y,w,h,bg) for background. Compute fillW = (uint16_t)(w * value). Clamp: if (fillW > w) fillW = w. If fillW > 0: fillRect(x,y,fillW,h,fg). Return 0.

- **lua_engine_ui_statBar(L)**: Extract x,y,w,h, current(float via luaL_checknumber), max(float via luaL_checknumber), fg, bg. Compute fraction = (max > 0.0f) ? (current / max) : 0.0f. Clamp fraction to [0,1]. Same fillRect pattern as progressBar using fraction. Return 0.

- **lua_engine_ui_panel(L)**: Extract x,y,w,h, bg(uint8), border(uint8). fillRect(x,y,w,h,bg). drawRect(x,y,w,h,border). Return 0.

- **lua_engine_ui_label(L)**: Extract x(int16), y(int16), str(luaL_checkstring), fg(uint8). drawText(str,x,y,fg,1,nullptr). Return 0.

Implement registerUISubtable(lua_State* L):

void LuaBindings::registerUISubtable(lua_State* L) {
