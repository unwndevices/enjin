```cpp
static void clearSlot(Slot& slot, lua_State* L) {

    slot.threadRef = LUA_NOREF;
    slot.waitRemaining = 0.0f;
    slot.id = 0;
    slot.active = false;
}
```

```cpp
static constexpr int TWEEN_POOL_SIZE = 8;

enum class TweenEasing : uint8_t { Linear = 0, EaseIn = 1, EaseOut = 2, EaseInOut = 3 };

struct TweenSlot {
    int      targetRef{LUA_NOREF};
    int      doneCbRef{LUA_NOREF};

    float    endVals[TWEEN_MAX_PROPS]{};

    float    elapsed{0.0f};
    float    duration{1.0f};
    TweenEasing easing{TweenEasing::Linear};
    int      id{0};
    bool     active{false};
};
TweenSlot m_tweenPool[TWEEN_POOL_SIZE];
int       m_nextTweenId{0};
```

**bindings_tween.cpp — Create new file** following bindings_async.cpp structure exactly:

1. **File header**: `@file bindings_tween.cpp` — engine.tween.* Lua sub-table (Phase 50: TWEEN-01..TWEEN-03)
2. **Include**: `bindings.hpp` and `bind_helpers.hpp` (same as bindings_async.cpp)
3. **Include**: `<cstdio>` for fprintf, `<cstring>` for strncpy/strcmp

4. **clearTweenSlot helper** — file-scope static, template-based like clearSlot in bindings_async.cpp:
   - Unrefs targetRef and doneCbRef if != LUA_NOREF
   - Resets all fields: targetRef = LUA_NOREF, doneCbRef = LUA_NOREF, propCount = 0, elapsed = 0.0f, id = 0, active = false

5. **tweenEase inline function** (file-scope static):
   - Linear: return t
   - EaseIn: return t * t (quadratic)
   - EaseOut: return 1.0f - (1.0f - t) * (1.0f - t)
   - EaseInOut: return t * t * (3.0f - 2.0f * t) (smoothstep)
   - CRITICAL: NO std::pow, NO sqrtf, NO libm calls — multiply/add only

6. **lua_engine_tween_to** (TWEEN-01):
   - Check args: arg1 = table (target), arg2 = table (props), arg3 = number (duration), arg4 = string (easing), arg5 = optional function (done_cb)
   - Find free slot via linear scan; return nil if pool full (no error raised)
   - Anchor target table via luaL_ref
   - Anchor done_cb via luaL_ref if provided (lua_isfunction check on arg 5)
   - Parse easing string: "linear"/"easeIn"/"easeOut"/"easeInOut" -> TweenEasing enum; default to Linear
   - Iterate props table via lua_next: for each string key with number value, copy key into slot.keys[propCount], store endVal, sample startVal from target table via lua_rawgeti(registry, targetRef) + lua_getfield
   - PITFALL: if lua_next loop exits early (propCount >= TWEEN_MAX_PROPS), must pop remaining key+value with lua_pop(L, 2) before breaking
   - Set elapsed=0, duration (clamp to 0 if negative), id=++m_nextTweenId, active=true
   - Return slot.id as lua_Integer
   - Clamp duration: `if (duration <= 0.0f) duration = 0.0f;` — allows instant completion on next tick

7. **lua_engine_tween_cancel** (TWEEN-02):
   - Get cancelId from arg 1 (luaL_checkinteger)
   - Linear scan m_tweenPool; if slot.active && slot.id == cancelId, call clearTweenSlot and break
   - Per Claude's discretion: cancel leaves value at current interpolated position (does NOT snap to end, does NOT fire done_cb)

8. **lua_engine_tween_cancelAll** (TWEEN-02):
   - Clear all active slots, reset m_nextTweenId = 0

9. **tickTweens(dt)** (TWEEN-01):
   - Guard: if (!engine) return; if (!getState()) return
   - For each active slot: advance elapsed += dt, compute t = elapsed/duration (guard: if duration <= 0, t = 1.0f), clamp t to 1.0f
   - Apply easing: float easedT = tweenEase(t, slot.easing)
   - Push target table from registry via lua_rawgeti; check lua_istable
   - For each property: compute val = startVal + (endVal - startVal) * easedT; lua_pushnumber + lua_setfield
   - Pop target table
   - If t >= 1.0f: fire done_cb via lua_pcall(L, 0, 0, 0) if doneCbRef != LUA_NOREF, then clearTweenSlot
   - done_cb errors: fprintf(stderr, "[tween done_cb error] %s\n", ...) and lua_pop(L, 1)

10. **clearTweens()** (TWEEN-02):
    - Get lua_State from engine
    - Loop all slots: if active, call clearTweenSlot
    - Reset m_nextTweenId = 0

11. **registerTweenSubtable(lua_State* L)**:
    - Static LuaFuncDef array: {"to", lua_engine_tween_to}, {"cancel", lua_engine_tween_cancel}, {"cancelAll", lua_engine_tween_cancelAll}
    - lua_newtable + luaBindFunctions + lua_setfield(L, -2, "tween")
