**Step 2: Create bindings_physics.cpp**

Create `src/scripting/bindings_physics.cpp` with all `engine.physics.*` binding implementations:

- Include `bindings.hpp`, `physics.hpp`, `types.hpp` (for Vec2 luaL_testudata), `tilemap.hpp`, `scene.hpp`, `object.hpp`, `collision.hpp`
- Each binding function is a static member of LuaBindings (matching the pattern of `lua_engine_collision_*`)
- All functions accepting position/velocity pairs: check for Vec2 userdata at arg 1 via `luaL_testudata(L, 1, "Vec2")`, fall back to `luaL_checknumber` pairs

Key implementation details:

**applyGravity** — Disambiguate by argument count:
- Vec2 input: arg 1 = Vec2, arg 2 = dt; if `lua_gettop(L) > 2` then args 3,4 = gx,gy override
- Number input: args 1,2 = vx,vy; arg 3 = dt; if `lua_gettop(L) > 3` then args 4,5 = gx,gy override
- When no override: use `b->m_gravityX, b->m_gravityY` from getBindings(L)

**raycast** — Two-stage scan:
1. Find first C_Tilemap in active scene (linear scan of objects, max 128). If found, run DDA:
   - Convert ray start/end to tile grid coords using sheet tileW/tileH
   - Walk tiles using Amanatides & Woo DDA (stepX/stepY, tMaxX/tMaxY, tDeltaX/tDeltaY)
   - First non-zero tile ID = hit. Compute hitX/hitY from ray parametric t
   - Return: `true, hitX, hitY, distance, "tilemap"`
2. If no tilemap hit (or no tilemap): linear scan scene objects. For each object with C_Position:
   - Use position as a point target (no bounding box). Check ray-to-point proximity via closest-point-on-segment.
   - Use a fixed hit radius of 8 pixels (reasonable default for game objects).
   - Track closest hit. Return: `true, hitX, hitY, distance, "object"`
3. If no hit: return `false`

NOTE: The raycast scans `m_activeScene` from getBindings(). If `m_activeScene == nullptr`, return `false` immediately (silent no-op, matching engine.camera.* pattern).
