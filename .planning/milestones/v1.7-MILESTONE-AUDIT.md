## Tech Debt

### Phase 48: Camera Follow

- **m_followTargetProxy not cleared in registerAll() or setActiveScene()** — After hot-reload or scene transition, the pointer could theoretically reference freed Lua heap memory. Safe in practice because `lua_ok` gating prevents tick before reload completes. Recommended fix: add `m_followTargetProxy = nullptr;` alongside `clearCoroutines()`/`clearTweens()` calls.

### Phase 51: Persistent Objects

- **PERSIST-01/02/03 are silent no-ops in SDL standalone mode** — No SceneStateMachine exists in standalone runner, so persist/unpersist/find return nil. This is correct by design (documented in source) but should be noted in API docs.

### Phase 47: Debug Draw

- **DEBUG-03 API naming** — Requirement says "engine.debug.enabled boolean toggle" implying field assignment. Implementation delivers `setEnabled()`/`getEnabled()` functions. Functionally equivalent; phase plan documents the design rationale.

**Total: 3 advisory items across 3 phases. 0 blockers.**
