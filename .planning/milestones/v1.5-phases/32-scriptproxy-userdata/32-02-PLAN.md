<objective>
Migrate all four existing Lua scripts to the new (self, ...) callback signature required by Phase 32, and verify the SDL runner integration is compatible.

Purpose: PROXY-04 requires atomic migration of all existing scripts from update(dt)/draw() to update(self, dt)/draw(self). The SDL runner calls g_lua.callFunction("update", dt) which pushes dt as the first positional argument. After migration, Lua receives self=nil (the runner pushes no proxy) and dt as the second. This is safe because none of the four scripts use self in their bodies — they only accept it as a parameter. Lua functions silently ignore nil for unused parameters.

Output: All four scripts updated with new signatures; pikachu_demo.lua fixed for dt seconds (removes obsolete * 1000); SDL runner verified to still work without modification.
</objective>

SDL runner (src/platform/sdl/sdl_main.cpp):
  Line 265: g_lua.callFunction("update", dt)
  Line 272: g_lua.callFunction("draw")

  LuaEngine::callFunction("update", dt) calls lua_pcall(L, 1, 0, 0) — pushes ONE argument (dt).
  After Lua migration to update(self, dt):
    - Lua assigns dt to the 'self' parameter (first positional arg), NOT nil.
    - dt is NOT received by the 'dt' parameter — it gets the value that was previously dt.

  THIS IS A BEHAVIORAL BREAK for scripts that use dt in their body.
  pikachu_demo.lua uses dt inside update(). If the runner pushes only dt and the script
  expects update(self, dt), then self=dt_value and dt=nil — updateSprite gets nil, which
  will error.

  DECISION REQUIRED (Claude's Discretion):
  Option A: The SDL runner is updated to push nil as first arg, then dt:
    lua_getglobal(L, "update");
    lua_pushnil(L);           // self = nil
    lua_pushnumber(L, dt);    // dt = dt
    lua_pcall(L, 2, 0, 0);
    (Same for draw: push nil as self)

  Option B: The SDL runner keeps calling callFunction("update", dt) unchanged, and the
  scripts use update(dt) not update(self, dt) — i.e., the SDL runner path is NOT migrated.

  Option C: The SDL runner is given its own proxy (a sentinel) — overkill for Phase 32.

  CORRECT CHOICE: Option A — update the SDL runner to push nil as self before dt.
  This aligns Lua behavior with PROXY-04 ("migrate scripts to new (self, ...) signature atomically")
  and means pikachu_demo.lua gets the correct dt value. The runner's nil proxy is safe because
  the scripts do not USE self in their bodies (they merely accept it).

  Implementation for sdl_main.cpp:
  Replace:
    enjin2::LuaResult r = g_lua.callFunction("update", dt);
  With a direct lua_State* call:
    {
        lua_State* L = g_lua.getEngine().getState();
        lua_getglobal(L, "update");
        if (lua_isfunction(L, -1)) {
            lua_pushnil(L);                          // self = nil (no proxy at runner level)
            lua_pushnumber(L, static_cast<lua_Number>(dt));  // dt
            int rc = lua_pcall(L, 2, 0, 0);
            if (rc != LUA_OK) {
                const char* err = lua_tostring(L, -1);
                std::cerr << "[lua error] " << (err ? err : "unknown") << "\n";
                lua_pop(L, 1);
                lua_ok = false;
            }
        } else {
            lua_pop(L, 1);
        }
    }
  Replace:
    enjin2::LuaResult r = g_lua.callFunction("draw");
  With:
    {
        lua_State* L = g_lua.getEngine().getState();
        lua_getglobal(L, "draw");
        if (lua_isfunction(L, -1)) {
            lua_pushnil(L);  // self = nil
            int rc = lua_pcall(L, 1, 0, 0);
            if (rc != LUA_OK) {
                const char* err = lua_tostring(L, -1);
                std::cerr << "[lua error] " << (err ? err : "unknown") << "\n";
                lua_pop(L, 1);
                lua_ok = false;
            }
        } else {
            lua_pop(L, 1);
        }
    }

  NOTE: sdl_main.cpp already includes bindings.hpp (via "#include &lt;enjin2/scripting/bindings.hpp&gt;")
  and lua_platform.hpp is transitively included — lua_State* and lua_pcall are available.
  LuaScriptSystem::getEngine().getState() returns lua_State*.
