**Step 1 — Fix scene.hpp (lines 119-124):**

Replace the existing `if constexpr` block inside `Scene::render<PixelType>()` (lines 119-124):

```cpp
// REPLACE THIS:
if constexpr (std::is_same_v<PixelType, uint8_t>) {
    onRender(canvas);
} else {
    // For non-uint8_t canvases, skip scene-specific rendering for now
    // In a full implementation, you'd convert or provide templated onRender
}
```

With:

```cpp
if constexpr (std::is_same_v<PixelType, Pixel4>) {
    onRender(canvas);
} else if constexpr (std::is_same_v<PixelType, uint8_t>) {
    onRender(canvas);
}
```

Do NOT collapse into a single `onRender(canvas)` call without `if constexpr` guards — it will not compile because `onRender` has two overloads for specific types and overload resolution needs a concrete argument type. Keep the two-branch form.
