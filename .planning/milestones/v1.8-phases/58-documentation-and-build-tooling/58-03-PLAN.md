end)
-- If tid is invalid or already complete: resumes immediately (no yield)
```

- engine.async.start(fn)       -- NOT engine.coroutine.start

- engine.tween.await(id)       -- NOT tween.wait or engine.tween.wait

[engine.async.wait(seconds) — suspends the coroutine for N seconds then resumes.]

engine.async.start(function()

## Waiting by Frames

[engine.async.wait_frames(n) — suspends for exactly N frames. Useful when timing must be frame-precise rather than time-based.]

Show a concrete example: e.g., give the player invincibility for 60 frames after taking damage:
```lua

    set_invincible(true)

end)
```

## Waiting for a Tween

[engine.tween.await(id) — suspends the coroutine until a specific tween completes. If the tween ID is invalid or already finished, resumes immediately.]

```lua
local tid = engine.tween.to(...)
engine.async.start(function()
    engine.tween.await(tid)

end)
```

## Combining Primitives

[Show a single small example combining all three in sequence — demonstrates the real power of the unified coroutine model. E.g., play an animation (tween), wait 1 second, flash for 30 frames:]

    engine.async.wait_frames(30)     -- flash for 30 frames
    engine.state.switch("next_level")

```

## Coroutine Pool
