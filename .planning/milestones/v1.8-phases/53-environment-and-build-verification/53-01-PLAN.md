<task type="auto">
  <name>Task 1: Verify ESP-IDF v5.5 git tag and create scripts/setup-dev.sh</name>
  <files>scripts/setup-dev.sh</files>
  <action>
First, verify the exact ESP-IDF v5.5 git tag by running:
  git ls-remote --tags https://github.com/espressif/esp-idf.git | grep "v5\.5" | head -10

The tag will be either v5.5 or v5.5.0 — use whichever appears in the output. If the network is unavailable, use v5.5 (the standard point-release pattern for ESP-IDF 5.x).

Then create scripts/setup-dev.sh with the following behavior:

1. Use `set -euo pipefail` as the first non-comment line after the shebang.
2. Define these path variables at the top:
   ```
   ENJIN2_TOOLS="$HOME/.local/share/enjin2"
   EMSDK_DIR="$ENJIN2_TOOLS/emsdk"
   ESPIDF_DIR="$ENJIN2_TOOLS/esp-idf"
   ```
3. Create the parent directory: `mkdir -p "$ENJIN2_TOOLS"`
4. Emscripten block:
   - If `[ -d "$EMSDK_DIR" ]` is true, print `"Emscripten already installed at $EMSDK_DIR"` then skip the clone.
   - Else, `git clone https://github.com/emscripten-core/emsdk.git "$EMSDK_DIR"`
   - Then (always runs): `cd "$EMSDK_DIR" && ./emsdk install 3.1.73 && ./emsdk activate 3.1.73`
   - Note: `./emsdk install` is itself idempotent — it skips if already installed.
5. ESP-IDF block:
   - If `[ -d "$ESPIDF_DIR" ]` is true, print `"ESP-IDF already installed at $ESPIDF_DIR"` then skip the clone.
   - Else, `git clone --depth 1 --branch <verified-tag> https://github.com/espressif/esp-idf.git "$ESPIDF_DIR"`
   - Then (always runs): `cd "$ESPIDF_DIR" && ./install.sh esp32s3`
   - Note: `./install.sh` is itself idempotent.
6. Print a blank line then a clear activation instructions block:
   ```
   Add the following to your ~/.bashrc or ~/.zshrc:

     source $EMSDK_DIR/emsdk_env.sh
     source $ESPIDF_DIR/export.sh
   ```
   Do NOT use echo to append to any shell config file — only print to stdout.
7. Add a comment near the top of the script noting that system packages (cmake, git, python3, python3-pip) must be installed by the developer separately (Arch Linux: `pacman -S cmake git python`).

After writing the file, run `chmod +x scripts/setup-dev.sh` to make it executable.
