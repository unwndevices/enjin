```markdown
# API Reference

Complete API documentation for enjin2, organized by module.

## Modules

- [Abstract](./abstract/) - Abstract interfaces for core engine components
- [Animation](./animation/) - Animation system and easing functions
- [Compat](./compat/) - Compatibility layer for enjin1 integration
- [Components](./components/) - Component types for game objects
- [Core](./core/) - Core engine components and systems
- [Effects](./effects/) - Post-processing effects
- [Graphics](./graphics/) - Graphics rendering system
- [Scripting](./scripting/) - Lua scripting integration
- [UI](./ui/) - UI system management
- [Utils](./utils/) - Utility functions and helpers
```

Key frontmatter details:
- `slug: /` makes this the root page for the API plugin (serves at `/enjin/api/`)
- `id: api-landing` avoids conflict with any module doc IDs
- `sidebar_position: 0` places it at the top of autogenerated sidebar

**2. Run full Docusaurus build** to verify no broken links:

```bash
cd docs && npx docusaurus build 2>&1
```

- Landing page routing issues
