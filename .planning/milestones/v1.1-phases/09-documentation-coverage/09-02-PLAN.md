<task type="auto">
  <name>Task 1: Document core module public APIs</name>
  <files>include/enjin2/core/*.hpp</files>
  <action>
    Add essential-level Doxygen documentation to all public APIs in include/enjin2/core/ directory:

    For each header file in core module (approximately 7 files):
    1. Add file documentation at top:
       ```
       /**
        * @file filename.hpp
        * @brief One-line file purpose
        */
       ```
    2. For each undocumented class: Add @brief description (one sentence)
    3. For each undocumented public function: Add @brief, @param for each parameter, @return for return value
    4. For each undocumented enum: Add @brief description
    5. For each undocumented public member variable: Add @brief if needed
    6. For template classes/functions: Add @tparam for each template parameter

    Documentation style:
    - Essential level only: brief description + parameters + return value
    - One sentence per concept
    - No code examples
    - No pre/postconditions
    - Document parameter constraints only when non-obvious (ranges, nullability, special values)
    - If purpose is truly unknown, use boilerplate: `/** @brief [TODO: Describe what this does] */`

    Use templates from 09-01-PLACEHOLDERS.md for consistency.
  </action>
  <verify>
    1. Run `doxygen Doxyfile`
    2. Run `grep "include/enjin2/core/" doxygen-warnings.log` - expect significant reduction in warnings
    3. Spot check: Open 2-3 core files and confirm @brief/@param/@return present
  </verify>
  <done>
    All public APIs in include/enjin2/core/ have essential-level Doxygen documentation (@brief, @param, @return, @tparam, @file as appropriate).
  </done>
</task>
