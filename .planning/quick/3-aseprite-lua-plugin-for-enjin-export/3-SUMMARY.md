# Quick Task 3: Aseprite Lua Export Plugin Summary

**One-liner:** Aseprite Lua plugin (351 lines) that exports indexed-color sprites to enjin C header format via File > Scripts dialog, format-identical to aseprite2enjin.py.

## What Was Built

## Script Architecture

Six logical sections as specified:

1. **validate_sprite** — checks sprite is open and in indexed color mode
2. **extract_frame_pixels** — composites visible layers for one frame, remaps transparent index to 15 with swap logic, applies `bit32.band(0x0F)` mask
3. **build_pixel_data** — dispatches to grid mode, single-frame, or multi-frame paths, matching Python's `build_pixel_array` logic exactly
4. **emit_header** — builds C header string with `table.concat`, 16 hex values per line, trailing comma on all lines except last line of last frame
5. **derive_name** — C identifier from file path using `app.fs.fileTitle()`
6. **run_export** — Dialog with output path, C identifier, grid cell W/H, Export/Cancel; calls above functions in sequence

## Format Verification

Output header format matches `tools/aseprite2enjin.py` exactly:
- First line: `// Generated by enjin-export (Aseprite plugin) from {filename}`
- Second line: `// Cell: WxH, Grid: CxR, Frames: N`
- `#pragma once` and `#include <cstdint>`
- `const uint8_t {name}_data[] = {`
- Per-frame: `    // Frame N` comment followed by pixel data lines
- 16 `0x%02X` values per line, comma-separated
- Trailing comma on every line except the very last data line of the very last frame
- Closing `};`, blank line, usage comment block
