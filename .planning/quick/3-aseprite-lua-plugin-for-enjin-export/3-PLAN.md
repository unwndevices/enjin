From tools/aseprite2enjin.py — C header format:
```c
// Generated by enjin-export (Aseprite plugin) from filename.aseprite
// Cell: WxH, Grid: CxR, Frames: N
#pragma once
#include <cstdint>

const uint8_t name_data[] = {
    // Frame 0
    0x0F, 0x0F, 0x0F, ... (16 hex values per line, comma-separated)
    // Frame 1
    ...
};

// Usage:
// #include "enjin2/graphics/sprite.hpp"
// enjin2::SpriteSheet name(name_data, W, H, C, R);
```

From include/enjin2/graphics/sprite.hpp — constructor signature:
```cpp
SpriteSheet(const uint8_t* d, uint8_t cw, uint8_t ch, uint8_t c, uint8_t r)
```

Key format rules:
- 1 byte per pixel, lower nibble = palette index (masked with & 0x0F, so 0x00-0x0F)
- Index 15 (0x0F) = transparent
- Frame data contiguous, row-major within each frame
- 16 hex values per output line
- Trailing comma on every line except the very last data line

Create a standalone Aseprite Lua script at `tools/aseprite/enjin-export.lua` that replicates the exact behavior of `tools/aseprite2enjin.py` but runs inside Aseprite's scripting engine.

**Script structure (single file, ~200-250 lines):**

1. **Validation function** `validate_sprite(sprite)`:
   - Check `app.sprite` is not nil (alert and return if no sprite open)
   - Check `sprite.colorMode == ColorMode.INDEXED` (alert if not indexed mode)
   - Return true/false

2. **Pixel extraction function** `extract_frame_pixels(sprite, frame_index)`:
   - Create a canvas buffer (Lua table) of size `sprite.width * sprite.height`, pre-filled with transparent index 15
   - Get the frame object: `sprite.frames[frame_index]`
   - Iterate over all layers via `sprite.layers` (skip non-visible layers via `layer.isVisible`)
   - For each visible layer, get the cel at this frame: `layer:cel(frame_index)` (may be nil if no cel on that frame)
   - If cel exists, get `cel.image` and `cel.position` (Point with x, y)
   - Iterate over cel image pixels using nested loops: `for y = 0, image.height - 1` / `for x = 0, image.width - 1`
   - Get pixel value: `local px = image:getPixel(x, y)`
   - Compute canvas position: `cx = cel.position.x + x`, `cy = cel.position.y + y`
   - If within canvas bounds, write to buffer: `buffer[cy * sprite.width + cx + 1] = px` (Lua 1-indexed)
   - Handle transparency remapping: if `sprite.transparentColor ~= 15`, remap that index to 15 in the buffer (swap: transparent pixels become 15, any pixel that was already 15 becomes the old transparent index)
   - Apply lower nibble mask: `bit32.band(px, 0x0F)` on each pixel value before storing
   - Return the buffer table

3. **Build pixel data function** `build_pixel_data(sprite, grid_w, grid_h)`:
   - **Grid mode** (grid_w > 0 and grid_h > 0): Take first frame only. Compute `cols = math.floor(sprite.width / grid_w)`, `rows = math.floor(sprite.height / grid_h)`. Extract cells in row-major order (for row, for col, for py, for px — matching Python's build_pixel_array grid logic exactly). Return pixel_table, grid_w, grid_h, cols, rows.
   - **Single frame** (#sprite.frames == 1 and no grid): Return frame pixels, sprite.width, sprite.height, 1, 1.
   - **Multi-frame animation** (no grid): Concatenate all frame pixel buffers. Return combined pixels, sprite.width, sprite.height, #sprite.frames, 1.

4. **C header emitter function** `emit_header(pixels, name, cell_w, cell_h, cols, rows, source_filename)`:
   - Build the header string using `table.concat` for efficiency
   - First line: `// Generated by enjin-export (Aseprite plugin) from {source_filename}`
   - Second line: `// Cell: {cell_w}x{cell_h}, Grid: {cols}x{rows}, Frames: {total_frames}`
   - Then `#pragma once` and `#include <cstdint>` and blank line
   - Array declaration: `const uint8_t {name}_data[] = {`
   - For each frame (0 to total_frames-1):
     - Comment line: `    // Frame {frame_idx}`
     - Pixel data: 16 values per line, formatted as `0x%02X`, comma-separated
     - Trailing comma logic: comma after every line EXCEPT the very last data line of the very last frame (match Python behavior exactly)
   - Closing `};`
   - Usage comment block with `enjin2::SpriteSheet {name}({name}_data, {cell_w}, {cell_h}, {cols}, {rows});`
   - Return the complete string

5. **Name derivation function** `derive_name(filepath)`:
   - Use `app.fs.fileTitle(filepath)` to get basename without extension
   - Replace non-alphanumeric/underscore characters with underscore
   - If starts with digit, prepend underscore
   - Fallback to "sprite" if empty

6. **Dialog and main function** `run_export()`:
   - Call `validate_sprite()` first
   - Derive defaults: name from `derive_name(sprite.filename)`, output path from `app.fs.filePath(sprite.filename)` with `.h` extension replacing `.aseprite`/`.ase`
   - Create Dialog with title "enjin Export":
     - `dlg:entry{ id="output", label="Output .h path:", text=default_output_path }`
     - `dlg:entry{ id="name", label="C identifier:", text=default_name }`
     - `dlg:separator{ text="Grid Mode (optional)" }`
     - `dlg:number{ id="grid_w", label="Cell width:", text="0" }` (0 = disabled)
     - `dlg:number{ id="grid_h", label="Cell height:", text="0" }` (0 = disabled)
     - `dlg:button{ id="export", text="Export" }`
     - `dlg:button{ id="cancel", text="Cancel" }`
   - Show dialog: `dlg:show()`
   - If cancelled or export not pressed, return
   - Read dialog data, call `build_pixel_data()`, call `emit_header()`, write file
   - Check if `sprite.transparentColor ~= 15` and print a warning via `app.alert()` noting the remapping
   - Show success alert with file path and summary (array name, byte count, cell size, grid, frame count)

7. **Script entry point**: Call `run_export()` at the bottom of the file.

**Important Lua/Aseprite API specifics:**
- Lua tables are 1-indexed; all buffer indexing must account for this (add +1 when writing, subtract -1 when reading for C output)
- Use `string.format("0x%02X", value)` for hex formatting
- Use `bit32.band(value, 0x0F)` for the lower nibble mask (Aseprite's Lua has bit32 available)
- Frame indexing in Aseprite Lua API: `sprite.frames[1]` is the first frame (1-indexed)
- `layer:cel(frame_number)` takes a frame number (1-based) or frame object
- `image:getPixel(x, y)` is 0-indexed for x, y coordinates
- For file writing, use `io.open(path, "w")` and `file:write(content)` then `file:close()`
- Dialog number fields: use `dlg:number{ id=..., label=..., decimals=0 }` for integers
- The comment in the header should say "enjin-export (Aseprite plugin)" not "aseprite2enjin.py" to distinguish the source

**Transparency remapping strategy:**
- Before storing each pixel, check: if pixel value equals `sprite.transparentColor` and that is not 15, store 15 instead. If pixel value equals 15 and `sprite.transparentColor` is not 15, store `sprite.transparentColor` (swap to avoid data loss). This ensures transparent pixels always map to index 15 in output regardless of the sprite's configured transparent color.
- Apply `bit32.band(value, 0x0F)` AFTER the remapping.
