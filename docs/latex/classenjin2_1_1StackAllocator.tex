\doxysubsection{Detailed Description}
Stack-\/based allocator for temporary allocations. 

Allocates memory linearly from a fixed buffer. All allocations can be freed at once with \doxylink{classenjin2_1_1StackAllocator_a414bd82160cf508b285c74351a91ed42}{reset()}, ideal for frame-\/based allocations.
