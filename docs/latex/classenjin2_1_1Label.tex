\doxysubsection{Detailed Description}
\doxylink{classenjin2_1_1Label}{Label} component for text display with word wrapping and styling. 

A versatile text display component that supports:\+
\begin{DoxyItemize}
\item Custom fonts (GFX-\/style fonts)
\item Text wrapping and alignment
\item Background colors and borders
\item Tooltip-\/style pointers
\item Opacity/\+blend modes 
\end{DoxyItemize}
