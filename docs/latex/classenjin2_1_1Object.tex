\doxysubsection{Detailed Description}
\doxylink{classenjin2_1_1Object}{Object} base class for game entities. 

The \doxylink{classenjin2_1_1Object}{Object} class is the base class for all game entities in the Enjin system. It manages components using static allocation and provides lifecycle methods.
