\doxysubsection{Detailed Description}
Image cache component for sprite management. 

Provides static memory allocation for 4-\/bit image data with efficient caching and frame-\/based animation support. Based on original Enjin \doxylink{classenjin2_1_1C__ImageCache}{C\+\_\+\+Image\+Cache} design.
