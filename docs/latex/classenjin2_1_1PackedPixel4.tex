\doxysubsection{Detailed Description}
Packed storage for two 4-\/bit pixels in a single byte. 

Efficiently stores two \doxylink{structenjin2_1_1Pixel4}{Pixel4} values in one byte, achieving 50\% memory savings compared to storing each pixel in a separate byte.
