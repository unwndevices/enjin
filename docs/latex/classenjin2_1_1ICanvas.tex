\subsubsection*{template$<$typename TPixel$>$\newline
class enjin2::\+\+ICanvas$<$ TPixel $>$}
Abstract canvas interface for drawing operations. 


\begin{DoxyTemplParams}{Template Parameters}
{\em TPixel} & Pixel type (e.\+g., \doxylink{structenjin2_1_1Pixel4}{Pixel4}, uint8\+\_\+t)\\
\hline
\end{DoxyTemplParams}
Provides a hardware-\/independent interface for all drawing operations. Both enjin1 and enjin2 can implement this interface for compile-\/time polymorphism.


\begin{DoxyTemplParams}{Template Parameters}
{\em TPixel} & Pixel type (e.\+g., \doxylink{structenjin2_1_1Pixel4}{Pixel4}, uint8\+\_\+t)\\
\hline
\end{DoxyTemplParams}
Provides a hardware-\/independent interface for all drawing operations. Concrete implementations handle the actual pixel storage and formatting.
