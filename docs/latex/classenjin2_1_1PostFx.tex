\doxysubsection{Detailed Description}
Post-\/processing effects system. 

Provides various visual effects that can be applied to canvases including CRT simulation, noise, blur, glow, etc. Based on original Enjin \doxylink{classenjin2_1_1PostFx}{Post\+Fx} with expanded functionality.
