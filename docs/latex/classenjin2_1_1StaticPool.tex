\subsubsection*{template$<$typename T, size\+\_\+t CAPACITY$>$\newline
class enjin2::\+\+Static\+Pool$<$ T, CAPACITY $>$}
Static memory pool for embedded systems. 

Pre-\/allocates storage for a fixed number of objects of type T. All allocations come from the pre-\/allocated pool, avoiding dynamic memory.

{\em T} & Type of objects to allocate \\
