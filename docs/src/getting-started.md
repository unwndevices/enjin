# Getting Started

Get enjin2 up and running in three simple steps.

## 1. Clone the repository

```bash
git clone https://github.com/unwndevices/enjin.git
cd enjin
```

## 2. Configure build

```bash
mkdir build && cd build
cmake ..
```

## 3. Build

```bash
cmake --build .
```
